# 本地语音输入演示

在开发服务器的会话 URL 上添加 `?voiceDemo=1`，可体验未配置语音服务时的输入流程。仅在开发构建且主机为 localhost、127.0.0.1 或 IPv6 loopback 时生效；生产构建不启用。

演示复用聊天输入框的波形、计时、停止和转写控件，但不访问麦克风、不生成或上传音频，也不请求语音转写接口。点击麦克风后显示模拟波形；停止后分段回填当前语言的示例文字。文字带演示标记，保留已有草稿，可编辑，不自动发送。退出演示会取消尚未完成的模拟转写，并恢复真实服务的可用状态；离开页面时清除计时器。

演示用于验证交互流程，不能评估语音识别准确率、真实响应速度、设备兼容性或麦克风权限流程。真实录音使用原有服务配置和实现。
