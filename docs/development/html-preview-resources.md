# HTML 预览的资源归属

HTML 使用什么 CSS 框架、是否引用 Tailwind、引用哪个版本，以及如何提供样式，由生成的 HTML 自己决定。平台提示词不规定这些选择。

消息内预览与文件预览不注入 Tailwind，不删除或替换文件自带的 Tailwind CDN 脚本，保留原有样式、资源地址及脚本加载属性。两种预览共用有时间上限的首次展示流程，不识别或等待某个特定 CSS 框架。平台仍保留尺寸适配、截图、批注等预览能力及既有 iframe 隔离。

首次展示先等待文档解析、当前生效的样式表（含 `@import`）及页面使用的字体处理结束，再完成尺寸适配，经过下一帧布局后撤掉加载提示。资源等待从预览脚本启动算起，最多 4 秒；样式或字体失败时展示已有内容并提示，超时也展示可用内容且不取消后台请求。图片、视频、长连接和任意后台请求不作为首屏等待条件。文件预览的脚本启动检查与资源等待分开，慢样式不会触发原来的 1.5 秒启动重试。后续样式或字体加载完成时更新适配，复用当前文档与交互状态。

消息内交互式 HTML 使用稳定视口，高度取 560px 与会话可阅读高度的 70% 中较小者；可阅读高度扣除顶部栏和输入区。生成中、加载中、完成、失败和重试共用该尺寸约束。预览不再通过内容变化测量整页并自动增高，保留 HTML 自带的 `100vh` 等视口布局。长内容在 iframe 内滚动，滚动到边界后才将滚轮交给会话；全屏切换复用同一文档并保留交互状态。宿主窗口或输入区尺寸变化时才重新计算预览高度。

原实现同时存在两个问题：提示词宣称平台会提供 Tailwind，但工作区原文件和受控浏览器没有该运行时；页面预览又会删除文件自带的 Tailwind 脚本，强行替换成平台的 v4 版本。因此可能出现预览与原文件效果不一致、v3 配置失效，或页面等待 Tailwind 而不显示。

文件存储和原文件下载保留原文，展示时才处理资源路径与 SVG 引用。平台不替 HTML 增加框架运行时或离线编译步骤。

现有自带资源的 HTML 不需重新生成。历史上只有 Tailwind 类名、既无 CSS 又无运行时的 HTML 将按原文显示；如要恢复这些文件的原设计，需要在 HTML 自身补齐样式或资源引用。平台不自动改写旧文件。外部资源是否可访问仍取决于相应地址和浏览器网络环境。

## 文件预览与资源包

已注册的 HTML 产物通过 `POST /api/v1/conversations/:id/files/:fileId/html-preview` 打开。接口校验当前用户、任务和文件归属，读取现有 `WebArtifactBundle` 快照，返回处理后的入口 HTML、私有入口地址、到期时间及缺少的文件列表。不创建公开站点，不修改历史快照，不需要数据库迁移。

浏览器 iframe 位于 `/html-preview/{session}/{entry_path}`，由同一目录解析 CSS、脚本、模块导入、字体、图片和相对页面链接。入口带 `previewId` 时返回共享引导页，宿主通过既有消息协议装入文档，保留缩放和标注能力。消息中的内联 HTML 和上传附件仍使用独立文档预览，没有资源包时不会猜测工作区文件。

预览凭证是随机的 256 位值，只授权一个用户、任务、文件及快照。会话保存在 Redis，有效期 15 分钟；宿主提前两分钟通过认证接口续期，保持相同入口地址和交互状态。资源请求重新检查账号状态、文件归属及快照摘要。到期、任务/文件不可访问或快照变动后拒绝访问。JWT 和对象存储键不传给 iframe。预览路径在 API 日志中脱敏，四种 Nginx 部署入口均关闭该路径访问日志。

资源响应提供正确 MIME、匿名 CORS、禁止缓存及 referrer 策略；HTML 和 SVG 直接访问仍受 CSP sandbox 约束。iframe 不具备 `allow-same-origin`。四种 Nginx 配置和 Vite 都必须把 `/html-preview/` 转发到 API，不能落入 SPA 或普通静态资源规则。

## 与公开站点共用处理

私有预览和 `/web/{slug}/_releases/{release}/{path}` 共用 `WebArtifactResources`：先验证资源大小与校验和，再处理原目录引用。公开站点沿用发布、停用、删除和账号状态检查，不依赖预览凭证，外部访客可直接访问。

浏览器沙箱无法通过 CORS 许可加载外部 SVG `<use>`。资源包内的 `sprite.svg#symbol` 因此在输出 HTML 时转为内联定义，同一图集只读取一次；ID、内部引用、渐变、裁剪及样式选择器统一隔离。禁止把脚本、事件处理器、foreignObject、SMIL 动画或 XML DTD 从图集中引入页面；这些内容会返回资源包错误，需要作者提供静态图集。外部网络 SVG 不由服务器下载。原文件和发布快照不被改写。

历史单文件 HTML 可继续预览；存在完整资源包的旧文件直接使用原快照。只有入口、缺少本地配套文件的历史 HTML 显示可读取部分并列出缺失项，发布仍拒绝不完整资源包。运行时资源加载失败也会在预览顶部提示，提供文件详情和重新加载操作。远程 CDN 保留原 URL，网络、CSP 和提供方 CORS 仍决定其可用性。

回归测试覆盖路径、模块/CSS/字体资源、SVG、权限撤销、会话期限及续期、六语言提示和既有预览交互。`apps/api/test/integration/web-sites-postgres.ts --serve` 在独立 PostgreSQL、Redis 和存储中提供真实注册、预览与发布链路，可供浏览器验证；不会读取应用 `.env` 或连接已有数据库。
