# 项目图标与颜色

项目菜单使用“编辑”入口。编辑和新建项目时，可以在名称输入框左侧打开图标选择器：上方为 12 种颜色（两行，每行 6 个），下方为 30 个 24px 的内置 Lucide 图标。点击“完成”关闭选择器，点击弹窗“保存”或“创建”才持久化；取消编辑不会改变项目。

图标与颜色统一展示在侧边栏、项目拖拽预览、输入框项目选择器及任务移动菜单中。中文、英文和语言回退使用同一组语义键。

## 数据与部署

- 正式迁移：`20260917150000_add_project_appearance`。
- 仅向 `projects` 新增 `icon varchar(32)` 与 `color varchar(16)`，默认值分别为 `folder` 和 `default`。已有项目、任务关联、文件、排序及名称全部保留；不涉及删除或类型转换。
- 创建、编辑请求允许省略外观字段：创建时使用数据库默认值，编辑时保持原值。返回的项目对象包含经过枚举验证的 `icon` 和 `color`，不接受自定义 SVG、URL 或任意颜色字符串。
- 部署顺序：先运行 `pnpm db:migrate:deploy`，再部署使用新 Prisma Client 的 API 和前端。新前端需要新版项目接口；更新前已打开的页面应刷新。
- 若需要回滚应用版本，保留新增列即可，不应删除列丢弃已保存的图标和颜色。

## 验证

`pnpm test:runtime:projects:postgres` 在独立 PostgreSQL 容器中从历史数据升级，验证默认外观、编辑保存、仅改名时保留外观、任务记录及文件保留，并核对原迁移校验和。不会读取或修改应用数据库。
