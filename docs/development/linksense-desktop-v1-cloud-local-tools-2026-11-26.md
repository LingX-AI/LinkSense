# LinkSense Mac 客户端 v1：云 Codex + 本机工具（文件 / 桌面 / 浏览器）

本规格取代原“双模式桌面 Agent”的第一版范围。任务与 Codex 都在云端执行；桌面端
只做壳、云模式和本机工具执行器，不运行本地 Codex、本地模型或随包 Node/Codex 运行时。

## 1. 目标与已定决策

四个核心场景：

1. **任务执行**：云任务在云端 runner 上跑，桌面端与 Web 一致。
2. **本地文件系统**：云端 Codex 读写用户授权的本机文件夹。
3. **Computer use**：云端 Codex 观察并操作本机桌面窗口。
4. **Browser use**：云端 Codex 通过本机 Chrome/Edge 扩展操作用户已登录的浏览器。

已定决策：

- 任务执行：**云端 Codex 编排**；不在本机跑 Codex。
- 文件写入：**任务级读写**——一次授权、逐条审计、可撤销。
- 桌面动作：**内部 dev-proof 包全开；正式发布先安全子集**。
- 浏览器：**本机 Chrome/Edge 扩展**，不是云端 Chromium。
- 包：内部 ad hoc + dev-proof；正式发布需 Developer ID；移除随包 Node/Codex。
- 版本：内部构建解析 `agent-desktop` 最新稳定版并校验 checksums；发布包记录并固定
  实际验证过的版本。
- 旧代码：本地执行/M1b 代码停用保留，打包时不再带运行时。
- 设备注册：**登录即自动完成**；客户端启动时恢复 Keychain 会话、幂等注册/续期设备并
  建立 WebSocket；UI 不出现配对码或“配对”动作。
- 产品语言：界面不出现“配对 / 设备 / Keychain / WebSocket”；只有“登录”“本机工具”
  “允许访问的文件夹 / 窗口 / 浏览器”。底层连接凭据自动签发、自动续期、自动撤销，
  用户无感。
- 设备身份仍是内部实现：稳定安装 ID + 账号 + 服务器 → 服务端设备行 + Keychain 设备
  凭据 + WS，用于路由、撤销和审计。用户只需在任务里授权具体工具。
- 启动顺序：恢复 Keychain 会话 → `ensure device`（同一安装 ID/账号/服务器幂等，
  轮换设备 token）→ 建立 WS。全程无用户动作。
- 显式“停用本机工具”或服务端撤销会持久化；自动注册不会覆盖，必须由用户重新启用。
- 切换账号先断开旧账号的设备通道，再为当前账号 `ensure device`；设备数量上限、
  重命名与审计保留。
- 旧配对码 UI 删除；服务端配对路由仅供夹具/其他客户端保留，后续可另行清理。

### 任务目标：只有云端

- 新任务一律在云端 runner 执行；UI 不提供 Run location，也没有默认运行位置设置。
- 移除：新任务 Run location、设置里的 Default run location、Continue on this Mac /
  Continue on the cloud computer、执行目标徽标。
- 设备/配对不再是执行目标，只用于本机工具（文件/桌面/浏览器）；设置页改为“本机工具”。
- API 对新的 `execution_target=local` 创建请求返回明确不可用；保留历史字段和已有
  local 会话只读，不迁移、不重放、不新建本地回合。

## 2. 架构

```text
云端 runner（Codex app-server，任务在此执行）
  -> 工具组：local_files.* / local_desktop.* / local_browser.*
  -> API 设备网关（账号、设备、任务、授权根、窗口/标签页授权、审计）
  -> 桌面设备 WebSocket
  -> 桌面桥（Go）
       -> 本机文件系统（授权文件夹）
       -> agent-desktop（GUI 驱动）
       -> Chrome/Edge 扩展（本地浏览器）
```

- **一条共用 lane**：三个工具组都走现有设备通道与受限 tool.request/response，
  不各做一套。
- 云端模型只看到虚拟根 ID、窗口/标签页句柄和相对路径；看不到本机绝对路径、设备
  凭据或供应商密钥。
- 旧客户端不协商这些能力；云端 Codex 不暴露对应工具。

## 3. 本机文件

- 登录并启动即自动注册本机工具设备，不需要配对码或额外启用动作；用户只需选择要
  共享的文件夹。
- 选择文件夹，设置只读/读写；每任务一个「允许访问本机文件」开关，默认关。
- 云端 Codex 工具：列目录、读、搜文本、写/改、创建、删除（删除进废纸篓）。
- 任务级读写授权绑定账号、设备、会话、回合、授权根；撤销或会话结束即失效。
- 路径锁在授权根内；拒绝 `..`、绝对路径、符号链接逃逸、跨根访问。
- 读有大小上限；二进制只返回元数据；搜索有结果上限并默认排除 `.git`、
  `node_modules` 等大目录。
- 写入前冲突检测（读取时的摘要/修改时间）；外部已改动则返回冲突，不覆盖。
- 审计保留相对路径、动作、结果、耗时；服务端只记根别名与元数据。

## 4. Computer use

`agent-desktop` 最新稳定版当前为 **v1.3.1**（2026-11-13），提供 61 个命令名、
57 个可执行命令。内部包开放完整用户动作集：

- 观察：`snapshot`、`find`、`get`、`is`、`screenshot`、`list-surfaces`
- 按 ref：`click`/`double-click`/`triple-click`/`right-click`、`type`、`set-value`、
  `clear`、`focus`、`select`、`toggle`、`check`/`uncheck`、`expand`/`collapse`、
  `scroll`/`scroll-to`
- 键鼠：`press`、`hover`、`drag`、`mouse-move`/`mouse-click`/`mouse-wheel`
- 应用/窗口：`launch`、`close-app`、`list-apps`/`list-windows`/`list-displays`、
  `focus-window`、`resize`/`move`/`minimize`/`maximize`/`restore`
- 剪贴板：`clipboard-get`/`set`/`clear`
- 等待：`wait`

不开放：`sandbox exec`（本地 Shell，不属于云任务）、`mcp`/`batch`（接口形态）、
`key-down/up`、`mouse-down/up`（引擎要求常驻 daemon，当前拒绝执行）。

约束与风险（内部包接受，发布前需解决或保持关闭）：

- `press/key` 在 v1.3.1 派发前只校验一次焦点，兄弟窗口抢焦点后不会复验。
- `scroll` 预检本身可能滚动页面。
- `launch` 需要应用白名单；`screenshot` 可能截到其他窗口且未绑定选中窗口身份。
- `clipboard` 读写系统剪贴板，涉及隐私。
- `drag` 需要窗口/坐标约束。
- 选中一个窗口、五分钟任务授权、暂停/恢复/停止、TCC（辅助功能/屏幕录制）、审计
  保留；内部 ad hoc 包每次重打包需重新授权。

正式发布子集：观察、点击、输入、只读等待；滚动在补充验证后开放；按键、拖拽、
启动应用、截图、剪贴板等引擎修复后再评估。

内部包使用 dev-proof（prepared hash）路径；正式发布仍要求 Developer ID 签名与
`--macos-release` 的 signer token。

## 5. Browser use

- 使用本机 Chrome/Edge 的 Manifest V3 扩展，复用已有配对、标签页授权、虚拟指针、
  截图浮窗和撤销。
- 云端 Codex 的 `local_browser.*` 工具经设备 lane 调用扩展；按标签页授权，撤销即时
  生效；截图限本回合读取，不进会话事件。
- 目标：扩展安装后通过账号自动连接，不引入新的配对码流程；如果浏览器要求一次
  明确授权，也只保留一次连接确认。扩展不可用时返回明确错误，任务可继续用其他工具。
- 不使用云端 Chromium 作为本机浏览器的替代；云端 `BrowserPanel` 保持现状。

## 6. 任务执行

- 云任务创建、SSE、文件/工件、知识库、连接器与 Web 一致。
- 云 Codex 只有在设备在线、任务已授权对应工具时才看到本机工具；离线时工具明确报错，
  任务保留草稿，不自动回落或重放。
- 不新增本地回合、本地 worker、本地模型代理或跨目标续接。

## 7. 包与版本

- 移除 `Contents/Resources/runtime` 下的 Node/Codex 运行时；保留 Go 壳、WebView、
  设备通道和 `agent-desktop` + helper（约数 MB）。
- 内部构建解析 `agent-desktop` 最新稳定 release，校验 `checksums.txt` 后打包，并
  记录实际版本；发布构建记录并固定已验证版本。
- 保留现有签名、公证、更新和诊断流程；更新与进行中云任务无互斥问题（没有本地回合）。

## 8. 实施切片

1. **云端工具 lane + 文件读**：登录即自动注册、删除配对 UI；共享 `local_files`
   协议；文件夹授权；API 白名单；runner 的云 Codex `list/read` 工具；桌面路径限制
   与审计。
2. **文件写/建/删/搜**：任务级读写、冲突、废纸篓、搜索限额、撤销。
3. **桌面核心**：观察/点击/输入/等待；内部 dev-proof；窗口选择、五分钟授权、
   暂停/停止、TCC。
4. **桌面完整动作**：滚动/按键/拖拽/启动/截图/剪贴板，仅内部包全开。
5. **本机浏览器**：扩展接入云任务，标签页授权/撤销/审计。
6. **包瘦身与回归**：移除运行时、latest 解析、四个场景端到端、安全回归。

## 9. 验收

1. 云任务中 Codex 读到、搜到、改写本机授权文件夹；文件实际变化，冲突不覆盖。
2. 越界路径、符号链接、跨根、未授权文件夹、撤销后访问全部拒绝。
3. 云任务中 Codex 选中一个本机窗口，完成观察、点击、输入、滚动等动作；暂停/停止
   生效；TCC 引导可用。
4. 云任务中 Codex 通过本机 Chrome/Edge 扩展操作已授权标签页；撤销后立即失败。
5. 设备离线时三类工具都返回明确错误；任务保留草稿，不重放。
6. 审计只含元数据与相对路径；服务端无绝对路径、文件内容、截图、键入文本或凭据。
7. 包内无 Node/Codex 运行时；内部包可完成以上场景，发布包只开安全子集。

## 10. 开放点

- 文件夹授权是否跨任务持久（当前按“持久授权 + 每任务开关”）。
- 删除是否始终单独批准，还是任务级读写即覆盖删除。
- 截图是否进入模型输入（需要模型支持图像，且只限本回合）。
- 扩展配对的测试机分发方式（内部安装包/开发者模式加载）。
