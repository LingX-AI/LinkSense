# 图片预览与文件交付

模型查看本地图片后，Runner 接收原生 `imageView` 完成事件。LinkSense 为任务页面补充受保护的图片预览，但不把这次读取计为模型使用文件服务。原生事件的类型、完成状态和路径脱敏规则保持不变。

## 数据与接口

- Runner 使用内部 `POST /internal/image-previews`，与模型交付文件使用的 `register_artifact` 分开。动态 Worker 通过 Runner 控制器转发到 API；控制器必须显式注册该路由，并沿用当前任务所有者与应用服务会话的鉴权范围。
- 原生 `imageView` 允许读取任务工作区、已授权 Skill 的素材目录和当前用户的托管临时目录；Docker Worker 还允许读取其独立的系统临时目录，用于展示裁剪等中间图片。本地进程与 standalone 模式不开放宿主机系统临时目录。普通 Markdown 图片不增加临时目录权限。Runner 在事件完成时复制图片到工作区的受控交接目录，API 只接收工作区相对路径；原始绝对路径仍按原规则脱敏，不传给 API 或前端。
- API 校验任务所有权、当前运行回合、工作区路径、真实图片类型和大小。只接受 PNG、JPEG、WebP，最大 25 MiB，同时受部署的上传限制约束。
- 已绑定附件的内容校验和、大小、类型与来源工作区一致时，复用附件 ID；同回合的相同预览也复用现有 ID。文件名不同不影响内容匹配。正式产物不参与预览复用，避免查看图片后误隐藏交付文件。
- 其他过程图片保存到任务工作区的 `.linksense/image-previews/`，记录为 `kind=image_preview`、`source=system_generated`、`storage_backend=workspace`、`downloadable=false`。不写 MinIO，不生成下载卡片、产物审计或“使用文件服务”事件。
- 新预览只发送通用的文件元数据事件；完成的查看事件携带 `fileId`。前端收到查看完成事件后刷新文件元数据，包含复用已有附件的情况。
- 前端通过附件内容接口或 `GET /api/v1/conversations/:id/files/:fileId/image-preview` 鉴权读取图片。接口重新校验路径、文件大小、校验和与 MIME，返回私有、不可缓存的图片响应。
- 浏览器对象 URL 在最后一个预览使用者退出后释放；读取晚于组件卸载完成时也会释放。

预览文件保存在完整的文件索引中，不作为用户附件、待发送文件、正式产物、图片交付画廊或任务产物库中的文件展示。原有产物登记仍生成可下载文件并保留文件服务活动。

## 历史、隔离与清理

通过前向迁移 `20261023090000_allow_conversation_image_previews` 扩展 `conversation_files` 的类型与状态检查约束，并约束新预览必须绑定回合、保存在工作区、具有图片类型和校验和且不可下载。保留所有现有字段和历史数据，不修改已发布迁移。仅检查 Prisma 中的字符串字段不能替代检查数据库中实际生效的 CHECK 约束。既有 `artifact` 图片继续通过原来的鉴权预览接口读取。

普通文件查询继续按当前 Codex 分支筛选。仅当当前已读取的事件或消息明确引用旧图片时，补取同一任务内已绑定的图片附件或已登记预览，排除正式产物和其他任务的文件。任务分叉时，分支内原有文件保留其用途；仅被引用、来源回合不在分支中的旧图片作为预览上下文绑定到复制后的引用回合，避免制造未绑定的附件或重复上传卡片。前端加载历史页面时合并预览索引，避免切换历史后丢失图片。

新快照跟随任务工作区现有的生命周期和清理机制，不额外产生对象存储中的待清理文件。数据库登记失败时删除本次创建的快照目录，保留源图片；清理失败沿用现有重试队列。

部署时先执行数据库迁移，再同步更新 API、Runner 和 Web，使专用预览接口及新增文件类型在各层一致。旧任务已经记录的文件服务活动不会被此次更新改写。已经结束且缺少预览 ID 的历史事件不会被重放或自动改写；页面明确显示图片暂不可用。

本地容器开发中的控制器源码同步不会更新已启动的动态 Worker。涉及预览来源目录等执行侧逻辑时，使用 `pnpm dev:worker:rebuild` 重建 Worker 镜像并刷新任务环境。

## 回归范围

| 场景 | 预期 | 验证边界 |
| --- | --- | --- |
| 上传原图、不同文件名的相同内容 | 复用已绑定附件，保留预览，不生成交付活动 | Runner、API、Web 单元测试 |
| 附件目录旁生成的裁剪图、工作区产物和 temp 目录、受控交接目录 | 为 PNG、JPEG、WebP 创建私有快照，源文件删除后仍可读 | 真实图片字节的 API 单元测试 |
| 用户托管临时目录、Docker 独立系统临时目录 | 仅对原生查看事件开放，先复制快照；本地进程不开放宿主机系统临时目录 | Runner 各运行模式与四张裁剪图回归 |
| 已授权 Skill 素材、未授权目录、符号链接越界 | 授权素材可预览，越界来源失败关闭 | Runner 权限回归 |
| 个人任务与应用服务任务、默认与规划模式 | 保留既有鉴权和原生状态，专用接口贯通 Worker、控制器与 API | HTTP 链路与执行池测试 |
| 新建快照、重复查看、正式交付 | 复用同回合快照；过程预览不挤占正式产物画廊和下载卡片 | Runner、API、Web 回归 |
| 旧库升级、全新安装、重复迁移 | 允许新预览；旧附件和产物、字段与迁移校验和保持不变；拒绝无回合、可下载、类型伪造等非法状态 | `pnpm test:image-previews:postgres`，独立 PostgreSQL 16 容器；CI 必跑 |
| 历史分页、分叉引用旧图 | 文件索引完整且不跨任务取图；分叉记录满足回合绑定约束 | 历史、分叉单元测试与真实数据库约束测试 |
| 接口失败、缺少引用、加载失败、源文件被修改 | 保留模型原生完成状态；明确显示不可用或允许重试；不暴露原始路径和错误详情 | API 安全与 Web 状态回归 |
| 折叠缩略图、保持大图打开、异步加载后卸载 | 引用仍存活时保留对象 URL，最后一个使用者退出时释放 | Web 缓存与大图生命周期测试 |

前端通过 Vitest/jsdom 测试；页面浏览器验收需按用户明确指示执行。单元测试、真实数据库迁移验证与真实任务链路验证是不同层级，不能互相替代。
