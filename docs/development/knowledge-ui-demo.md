# 本地知识库 UI 示例

需要同时查看自动化、插件中心和资料库时，使用[工作区 UI 示例入口](workspace-ui-demo.md)；以下入口继续保留为单模块模式。

开发服务器打开 `/knowledge-bases?knowledgeDemo=1`，可在 Core 版环境中查看知识库的现有 UI。仅在开发构建、loopback 主机及 `/knowledge-bases` 路由内启用。当前浏览器标签页通过 sessionStorage 记住示例模式，便于进入详情、文档预览和刷新；不影响其他页面或其他标签页。

示例包含 8 个虚构知识库，覆盖自己创建、团队共享、已归档、停用和空库；文档覆盖 PDF、Word、Excel、PowerPoint、Markdown，以及就绪、处理中和失败状态。文档名称与正文是虚构的中文测试资料。搜索、所有权和归档筛选、详情列表及解析正文均复用现有组件。

示例数据由前端内存提供，不修改安装版本、后端能力、登录会话、数据库或真实文件。所有写权限关闭，知识库 API 在示例模式下拒绝写请求，上传也被阻止；不连接文档 SSE、不访问文件存储，下载入口禁用。处理中状态仅用于检查显示效果，不会启动真实解析任务。示例列表和能力查询使用独立缓存键，避免将模拟能力带到会话页等真实功能。

点击页面提示中的“退出示例”会移除当前标签页的开关并重新加载正常资料库；Core 版会恢复原来的安装提示。生产构建即使带有此 URL 参数也不会启用示例。
