# 本地工作区 UI 测试数据

在本地开发服务器打开 `/automations?workspaceDemo=1`（也可从 `/capabilities?workspaceDemo=1` 或 `/knowledge-bases?workspaceDemo=1` 进入）。页面显示只读示例提示，并在当前标签页的 sessionStorage 中记住开关，便于通过侧栏切换自动化、插件中心和资料库及刷新页面。仅限 Vite 开发构建和 loopback 主机；不改变登录、安装版本或后端能力。

示例内容：

- 自动化：6 条记录，含开启、暂停、上次执行失败、未执行过及长标题；支持列表筛选和打开编辑表单。
- 插件中心：5 个个人应用、3 个共享应用及对应应用中心条目，6 个插件、5 个技能、公开目录示例、5 个连接器状态、3 个 MCP 连接及 ClawHub 的虚构目录。应用详情、搜索和类型筛选沿用现有界面。所有名称中的“示例”或“Demo”均指虚构数据；MCP 地址及连接器账号使用保留的 `.invalid` 域名，不包含凭据或可运行的包。
- 资料库：复用[知识库示例数据](knowledge-ui-demo.md)中的 8 个知识库及文档，支持搜索、共享/归档筛选、文档详情和解析正文。

数据通过前端 API 适配器提供，仍由原有 Zod 响应 schema 校验。主要列表查询使用独立示例缓存键。示例模式内的业务写请求、上传、执行流和资源下载在请求发出前被拒绝；认证刷新和退出登录继续正常工作。未知的示例资源读请求也不会回落到真实 API。资料库沿用其只读权限和禁用 SSE、文件下载的处理。会话、设置等其他页面继续使用真实数据。

点击“退出示例”会清除当前标签页开关并完整刷新，以清空示例查询缓存；从资料库详情退出时回到真实列表。原有 `knowledgeDemo=1` 和 `pluginDemo=1` 单模块入口继续可用。生产构建不会启用示例，即使 URL 或浏览器存储中保留开关。

验证入口：`src/features/ui-demo/workspace-ui-demo.test.tsx`，覆盖本地/生产边界、跨模块导航、缓存隔离、响应契约、搜索筛选、只读限制、真实请求回退、实际自动化页面渲染及六语言提示。
