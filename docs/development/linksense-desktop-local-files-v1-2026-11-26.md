# LinkSense Mac 客户端 v1：轻客户端 + 本机文件（2026-11-26）

本规格取代原“双模式桌面 Agent”的第一版范围。桌面端不再运行本地 Codex，只保留
壳、云模式和本机文件桥；本地执行、M1b GUI、随包运行时不在 v1。

## 1. 目标

用户在 Mac 上使用与 Web 一致的 LinkSense 云任务，同时让云端 Codex 直接读写
用户明确授权的本机文件夹。文件不整体上传，模型只通过受限文件工具访问授权根内的
相对路径；写入按任务级授权执行并审计。

已定决策：

- **产品形态**：A，轻客户端 + 本机文件桥；不在本机运行 Codex。
- **写入授权**：任务级读写——用户在本任务内一次允许写选定文件夹，写入/创建/删除
  按此执行并逐条审计，可随时撤销。
- **旧代码**：本地执行/M1b 代码停用但保留在仓库；打包时移除随包 Node/Codex
  运行时，v1 包不再包含本地运行环境。

## 2. 范围（v1）

### 2.1 桌面壳
- 原生窗口、沉浸式标题栏、100% 缩放、窗口状态恢复。
- 系统浏览器登录、Keychain 会话、退出与切换账号。
- 菜单/托盘、通知、下载、诊断导出、应用内更新、六语言。

### 2.2 云模式
- 会话/任务、SSE 流式与重连、文件/工件、云端浏览器面板。
- 知识库、连接器、设置；与 Web 行为一致。

### 2.3 本机文件（v1 核心）
- **启用本机文件访问**：登录后一键把本机登记为文件提供方，不需要配对码。
- **文件夹授权**：用户选择一个或多个文件夹，设置只读或读写；可随时撤销。
- **任务级开关**：每个任务有“允许访问本机文件”，默认关；开启时选择授权文件夹。
- **任务级读写授权**：用户在本任务内一次性允许写选定文件夹；写入/创建/删除按此
  执行并逐条审计，撤销后立即拒绝新操作。
- **云端 Codex 工具**：列目录、读文件、搜文本、写/改文件、创建文件、删除文件。
  删除进入废纸篓，不直接 unlink。
- **路径与安全边界**：
  - 模型只看到授权根的虚拟 ID 和相对路径，不看到本机绝对路径。
  - 拒绝 `..`、绝对路径、符号链接逃逸和跨根访问。
  - 读有大小上限；二进制只返回元数据。
  - 写入前做冲突检测（读取时的内容摘要/修改时间），外部已改动则返回冲突，不覆盖。
- **离线与撤销**：Mac 离线时工具返回明确错误；撤销文件夹或整台 Mac 后，在途请求失败，
  新请求立即拒绝。
- **审计**：本地审计保留相对路径、动作、结果、耗时；服务端只记根别名与元数据，
  不记绝对路径、文件内容或键入文本。

## 3. v1 不做

- 本地 Codex、Shell、沙箱、本地模型代理。
- M1b 本地 GUI 控制、系统 TCC、浏览器扩展。
- 本地知识库/连接器、本地工作区保留、跨目标续接。
- Windows。

## 4. 架构

```text
云端 runner (Codex app-server)
  -> local_files MCP 工具
  -> API 设备网关（设备/账号/会话/授权校验、白名单、审计）
  -> 桌面设备 WebSocket
  -> 桌面文件桥（Go：授权根、虚拟路径、冲突检测、审批、审计）
  -> 本机文件系统
```

- 设备身份复用现有设备通道与 Keychain 凭据；“配对”在 UI 中改为“启用本机文件访问”。
- 文件工具通过现有受限 tool.request/response 通道下发，新增 `local_files.*` 操作集；
  旧客户端不协商该能力，云端 Codex 不暴露这些工具。
- 服务端不持有本机绝对路径；桌面端负责根映射与权限。
- 任务级读写授权绑定账号、设备、会话、回合和授权根；撤销或会话结束即失效。

## 5. 验收

1. 登录后一键启用本机文件访问；选择一个测试文件夹。
2. 创建云任务，开启“允许访问本机文件”，选择该文件夹。
3. Codex 能列目录、读文件、搜文本；文件内容来自本机而非上传副本。
4. 开启任务级读写后，Codex 能修改/创建文件；本机文件实际变化；删除进废纸篓。
5. 文件被外部改动后再写，返回冲突且不覆盖。
6. 越界路径、符号链接、跨根访问、未授权文件夹全部拒绝。
7. 撤销授权或断开 Mac 后，工具立即失败，任务保留可编辑草稿。
8. 审计只含相对路径与元数据；服务端无绝对路径、无文件内容。
9. 包内不再包含本地 Codex/Node 运行时；应用体积显著下降。

## 7. 实施切片

1. **端到端读**：共享 `local_files` 协议；桌面一键启用与文件夹授权；API 设备文件
   工具白名单；runner 的云端 Codex `local_files.list/read` 工具；桌面文件桥的
   路径限制与审计。验收：云任务里的 Codex 读到本机文件。
2. **写/建/删**：任务级读写授权；写入、创建、删除；冲突检测；删除进废纸篓；
   撤销即时生效。验收：Codex 修改本机文件，冲突不覆盖，删除可恢复。
3. **搜索与硬化**：文本搜索、排除规则、大小/二进制限额、本地审计视图、Web 任务
   开关与授权 UI、六语言。
4. **包瘦身与回归**：打包移除随包 Node/Codex 运行时；验证设备通道、更新、诊断、
   云模式与文件桥在无本地运行时的包内工作；安全回归（越界、符号链接、跨根、
   撤销、离线、跨账号）。

## 8. 开放点

- 文件夹授权是否跨任务持久（按账号+服务器保存，可撤销）还是每次任务重新选；
  当前按“持久授权 + 每任务开关”设计。
- 文件搜索的范围与排除规则（默认排除 `.git`、`node_modules` 等大目录）。
- 写入冲突时是否提供“覆盖/另存/放弃”三选，还是直接报错让 Codex 重读。
