# LinkSense UI 设计基线

本文件是后续 UI 开发的仓库入口，和主题变量、共享组件一起使用。2026-10-24 已将基线扩展到现有 Web 页面的共享外壳、表单、列表、弹窗和聊天呈现；有稿的页面参考个人 Figma 副本，其他页面复用本规范。2026-10-28 对照新的个人副本补齐侧栏、图标、颜色及页面家族差异；本轮来源与验证见 [适配复核](linksense-ui-fidelity-followup-2026-10-28.md)。此前覆盖见 [适配盘点](linksense-ui-adaptation-inventory-2026-10-23.md)。297 个设计画板包含状态变体，不等于 297 个业务页面。

## 使用顺序

1. 保留真实业务、接口、资源权限、Codex 原生生命周期、可访问性与已有用户偏好。
2. 有明确稿件时参考相应节点；缺稿时复用本文件、语义 token 和同类页面，不以补画 Figma 为前置条件。
3. 实现存在约束时完成可行部分，说明实际差异；常规布局、交互和可读性问题应直接修复。
4. 普通页面无需重新读取整份 Figma。新稿、规范更新或现有基线无法解释的关键视觉差异，再按需读取相关节点。

## 代码入口

| 能力 | 入口与约定 |
| --- | --- |
| 主题与排版 | `apps/web/src/index.css` 中的 `:root`、`.dark`、`@theme inline` 是取值来源。复用语义色、标题层级、字体、圆角和间距，不在页面散布近似颜色；不另维护一张数值表。 |
| 页面与顶栏 | `components/shell/page-layout.tsx`、`page-top-bar.tsx`、`settings-shell.tsx` 管理顶栏、内容宽度、页面标题、说明和操作区；设置内复用 PageLayout 时不重复显示顶栏。工作区通知置于侧栏品牌栏的搜索图标左侧，通过 `shell-header-actions.tsx` 将同一个通知按钮挂载到当前可见的桌面侧栏或移动导航品牌栏，保留原有查询和已读行为。桌面侧栏收起或移动导航关闭时隐藏入口，通过展开导航访问通知，不再回落到主内容顶栏，也不重复通知入口。 |
| 基础控件 | `components/ui/` 复用 Base UI 的键盘、焦点、禁用、表单和弹窗语义。Input、InputGroup、PasswordInput 默认描边；嵌套或透明编辑控件可显式使用 `variant="default"`，避免双重边框。 |
| 空状态 | `components/feedback/page-state.tsx` 的 EmptyState 统一渲染图标、标题和说明：未传 `icon` 时使用 Info 图标，未传 `description` 时回落到 `common.emptyDescription`，只保留标题时传 `description=""`。列表页空态优先给出真实创建入口；筛选或搜索无结果时只保留图标和标题，不重复创建动作。 |
| 分段标签 | `components/ui/tabs.tsx` 的 TabsList 默认采用 Segmented；插件中心一级导航用 `navigation` 下划线，应用范围及插件中心二级内容范围用 `catalog` 灰底卡片色选中块，资料库导航和自动化状态筛选用 `pills`。按用户后续要求，蓝色 Tab（`navigation` 与 `pills`）悬停不铺底色，仅保留文字反馈；当前选中的蓝色下划线或浅蓝色选中块以及键盘焦点提示继续保留。周期、分组、其他内容范围、运行位置、上传方式与认证方式仍复用默认变体；单个活动背景复用 Base UI 的容器内测量结果，由现有 Motion 平滑移动与缩放。路由会重建列表时，以稳定且唯一的列表 id 维持背景连续性；其他实例自动隔离。保持横向滚动、竖向标签、键盘和减少动态效果支持，不在页面叠加旧下划线或独立选中背景。 |
| 操作按钮 | 默认与 `brand` 使用实色主色及悬停色；保留已有紧凑尺寸和明确的图标按钮尺寸，不按一张画板统一放大所有密集操作。账号提交继续保留原有较大触达区。 |
| 卡片聚光 | `components/ui/card-spotlight.ts` 从 React Bits SpotlightCard 适配局部装饰；自动化模板、应用卡、站点卡、能力条目与知识库入口通过 `cardSpotlightProps` 复用。保留其 className 与现有类合并；仅精细指针悬停且未减少动态效果时跟随光点，键盘焦点使用静态边缘高亮。首页快捷卡不叠加聚光，悬停只用 1px `--input-hover` 描边、聚焦只用 1px `--ring` 描边。其他卡片和列表保留各自的裁切与描边。无常驻帧循环、额外布局容器或点击拦截，许可见 `THIRD-PARTY-NOTICES.md`。 |
| 设置分区 | `components/settings/settings-card.tsx` 的 `layout="split"` 将类别标题、说明和图标置于左侧，字段卡片置于右侧；随内容容器宽度堆叠。默认 stacked 仍用于管理表单等场景。两种排列共用四边相等的内边距，布局变体只调整排列和内容间隔。 |
| 账号访问 | `components/auth/account-access-layout.tsx` 统一品牌面板、语言选择、表单阅读宽度和归属标记；`AccountAccessHeading` 管理登录/找回的标题层级。注册、激活、重设密码、初始化与身份回调复用同一外壳。 |
| 聊天与输入 | `features/conversations/conversation-thread.tsx`、`conversation-composer.tsx`、`conversation-model-selector.tsx` 沿用原有消息、执行、输入和资源状态。项目选择器在输入工具栏内，创建项目只提交项目表单。 |
| 首页与共享页 | `new-task-welcome.tsx` 复用真实问候和提示词；`pages/shared-conversation-page.tsx` 复用首页渐变素材，展示标题、快照时间和只读说明。 |
| 文案与素材 | 新的账号、首页、设置分区及共享快照文案覆盖六语言。图片保存在 `assets/brand/` 和 `assets/home/`，不能使用临时 MCP 下载链接或整页截图作为运行界面。 |

## 视觉与响应式规则

- 整体采用纯白主内容区、白色卡片与顶栏、淡蓝消息表面和蓝色操作与选中状态。正文、辅助文字、边框与分隔线有各自语义；暗色通过相同角色适配。
- 区分页面主标题、分区标题、正文、字段标签、辅助说明。系统字体优先，保留本地 Inter / Noto Sans SC 等回退与用户字号偏好；不分发 SF Pro，也不承诺跨平台文字栅格化完全相同。
- 用 Tailwind 工具类完成页面布局、状态和断点。容器查询根据实际可用宽度调整卡片、设置分区与输入工具栏；少量 CSS 用于全局 token、复杂状态及既有聊天测量布局的衔接。
- 页面居中且有阅读宽度上限；宽数据表使用自己的水平滚动区，不能让整页横向溢出。弹窗宽度受视口约束，内容超高时滚动，保持关闭和提交可达。
- 普通弹窗、确认弹窗和抽屉统一复用 `--app-dialog-overlay`，浅色恢复原有 40% 蓝灰遮罩、深色为 65% 黑色，强化内容与背景的层次。普通弹窗保留细边框，不模糊背景；全屏图片预览在浅色下复用同一遮罩色，保留原有模糊，深色继续使用更深的 92% 黑色底。搜索采用紧凑的分组结果面板；项目、分享和确认弹窗复用同一视觉层级。
- 主题预览展示浅色、深色和系统模式，选择与本机持久化机制不变；字号输入保留原有范围和键盘行为，并展示实际字号的本地化示例文字。
- 手动切换主题时使用原生 View Transition，从视口右上角以圆形裁剪揭开新主题，约 650ms 缓入缓出，最终半径按视口对角线计算以覆盖全屏；浅色和深色均向外扩张。首次加载、颜色未变、减少动态效果偏好或浏览器不支持时直接应用主题。快速切换以最后一次选择为准。
- 长译文允许换行和自然增高。移动端隐藏装饰图，表单按自然文档流滚动；标题、菜单、模型名和资源名的截断只用于明确受限的区域，并保留完整内容的访问入口。
- 装饰图使用等比缩放与裁切，不能用独立百分比宽高拉伸。产品标志继续复用现有自定义品牌和暗色资源；不固定设计稿中的用户姓名、头像或示例数据。
- 保留语义标签、错误关联、密码显隐、自动填充、可见焦点和禁用说明。品牌蓝与选中表面遵循当前 Figma；白色小字动作、小字蓝色前景及辅助文字单独使用可读性语义色，具体例外见适配复核。`DesignIcon` 保留原始 Figma SVG，默认渲染尺寸随 UI 字号变化，默认字号为 14px 时图标为 16px；有明确用途的尺寸变体继续由调用处指定。应用、项目等动态身份按实际资源显示。

顶栏的搜索、侧栏切换、分享、任务概览和通知统一使用 `HeaderIcon`：在最终 20px 网格上绘制，保留原稿的图标语义，分别校准圆形、矩形与开放轮廓的比例、留白和视觉线宽（1.6–1.7px），列表使用 2px 实心圆点。`HeaderIconButton` 统一复用共享 Button 的 `icon-sm` 规格，默认管理 28px 透明底座和 6px 圆角，侧栏品牌栏的通知、搜索、收起沿用同一规格，默认前景通过 `--app-header-icon` 混合主文字与辅助文字色；悬停、按下和任务浮层展开时均保持图标原色，聊天顶栏显示中性灰底；侧栏通知、搜索、侧栏切换与底部帮助按钮的悬停、按下底色复用列表的 `--app-sidebar-hover`；帮助菜单展开时也沿用该底色，键盘聚焦保留 2px 焦点环。通知仅显示在侧栏品牌栏，收起侧栏后不再回落到主内容顶栏，并移除该入口旁的分隔线；窄屏通过展开导航抽屉访问通知。分享和任务概览图标显示为 16px，与侧栏品牌栏图标一致；底座、悬停、按下及浮层展开状态统一为 28px 和 6px 圆角，保留原有交互反馈。折叠侧栏后的恢复入口同步采用 16px 图标、28px 点击区和 6px 圆角，底座收紧后仍与顶栏垂直居中。侧栏品牌栏、任务行的归档与更多、底部帮助统一显示为 16px；归档、帮助和更多复用 HeaderIcon 的 20px 绘制网格及 1.65 线宽基准，更多保留实心圆点，并按实际显示校准为约 2.24px 直径，避免统一尺寸后圆点过细。Recent、置顶和项目子任务共用这一规则，点击区域和交互保持原样。此为当前开发效果的视觉优化，Figma 原始图标保持原状。

输入、搜索、多行输入及下拉框的空值提示统一复用 `--placeholder-foreground`（Tailwind 为 `text-placeholder-foreground`），与次要正文色分开维护。占位提示在当前主题的辅助文字色与输入表面色之间混合，视觉调浅；聊天主输入、附件搜索和全局搜索同步使用，不改变实际输入内容、标签或辅助说明的颜色。

## 页面家族的实现约定

### 任务、项目、搜索与分享

侧栏沿用真实置顶、项目、最近任务和账户功能。品牌栏按通知、搜索、收起的顺序排列，不再显示独立搜索栏。根据用户对顶部密度的最新调整，仅这三个入口采用 16px 图标、28px 点击区和 6px 圆角，通知与搜索的点击区域间隔 2px，收起入口通过 12px 高的细分隔线与额外留白分组；品牌标志高度收至 24px，操作图标恢复使用共享的 `--app-header-icon` 原色，悬停时保持图标颜色。品牌栏与聊天顶栏共用高度变量，保留品牌栏底部的横向分割线，与右侧顶栏保持连贯，与 Logo 保持一致的 16px 侧栏内边距；收起入口使用双左箭头，展开入口使用双右箭头，去掉原来的分栏方框；线条和悬停颜色继续复用现有组件。通知在桌面侧栏或移动导航抽屉中显示，不再回落到主内容顶栏。分组标题为 12px 常规字重，鼠标环境使用紧凑行高，触屏保留 40px 点击区；分组收起时持续显示右向箭头；展开时箭头和操作在悬停、键盘聚焦、菜单展开或触屏时显示。工作区导航、项目、置顶和最近聊天（含项目子任务）统一复用 `--app-sidebar-row-height` 的 34px 行高，新任务按钮共用该高度；粗指针触屏恢复为 40px，项目子任务整体缩进 24px；菜单和信息气泡锚定行右侧、顶部对齐、间隔 8px。子菜单保留原生触发项锚点，偏移计入父菜单内边距，保证间距和原生悬停交互一致。Ctrl/⌘K 打开并聚焦搜索，包括侧栏收起及窄屏；指针在窄屏打开搜索仍沿用不自动弹出键盘的行为。默认宽度参考设计稿，已有本地保存宽度继续生效。首页提示卡只填入草稿，不自动发送；欢迎区初次停在顶部，聊天仍按原有滚动策略定位最新消息。

全局搜索复用 CommandDialog 与分组列表，搜索栏、结果图标和标题共用对齐轴；结果按单行与带摘要两种密度展示，继续收紧结果行、组标题和图标占位，时间与来源信息在右侧固定栏对齐。线性图标复用顶栏的 20px 绘制网格、圆端线条和 16px 显示尺寸；结果行线性图标在浅色下使用黑色，深色下使用正文前景色，文件及能力身份图标统一在 20px 占位中显示为 16px。面板按内容收缩并限制滚动高度，焦点下的长分割线使用中性颜色，保留键盘聚焦与方向键选择反馈。窄屏、深色、大字号以及加载、空结果和错误状态沿用同一结构。本次按用户截图要求完成代码视觉优化；Figma 连接不可用，尚未同步核验。

设置侧导航沿用首页的 `--app-sidebar-row-height`、相邻 2px 间距、常规字重与侧栏交互色；返回入口与搜索框共用该高度，品牌栏与首页顶栏对齐。分组标题保持相同辅助文字层级，标题到列表间距为 2px，组间使用 12px 留白。导航图标继承文字前景色，并按 `--app-ui-font-size` 同步缩放；Lucide 图标使用标准 2px 描边，在相同显示尺寸下与首页资产保持一致的线条重量。插件中心、资料库与归档复用已有 `DesignIcon` 资产，不另用不同语义图形。搜索、返回位置和管理权限保持原有行为。

侧栏任务标题保持统一左内边距，通过 `text-spacing-trim: trim-start` 收紧行首全角括号等标点的半字留白，使中文示例与英文标题的可见左边缘对齐；不修改任务名称、不按语言添加不同缩进。置顶、最近任务与项目子任务沿用同一标题样式。

项目与聊天行的“更多”统一使用 `SidebarMoreIcon`：14px 的 Lucide `EllipsisIcon`，三个圆点更饱满、视觉间距更紧凑，颜色通过 `--app-sidebar-action` 跟随主题。归档、更多、分组排序与新建加号共用 `SidebarActionIcon` 的 28px 圆角底座；默认透明，直接悬停、键盘聚焦或菜单展开时通过 `--app-sidebar-action-hover` 显示清晰的浅蓝底色，悬停与展开时图标加深。此为用户在核对 [Figma 原组件 `1:8336`](https://www.figma.com/design/GIy53t29UhECq6RxUx2CbA/Linksense?node-id=1-8336) 后要求的开发效果优化，未修改 Figma 原组件。项目按钮居中置于行末与项目行同高的 34px 点击区，粗指针触屏随行高恢复为 40px。聊天行右侧归档与更多操作各使用 28px 点击区，垂直居中；归档图标使用 18px 容器补偿原始资产内留白，两者统一使用 `--app-sidebar-action`。操作区与文字之间保留 8px 安全间距，悬停、键盘聚焦和菜单展开时同步为文字留位。
