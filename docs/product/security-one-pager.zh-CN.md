# LinkSense 安全能力一页纸

> 对外材料。口径已按实际实现核对,「边界」一节请原样保留。

## 一句话

**AI Agent 在用户自己的电脑上干活,但每一步都经过企业侧授权、留痕、可随时撤回;发送给大模型的内容,在离开 LinkSense 之前先完成敏感信息脱敏。**

---

## 能力一:本地执行 —— 可控、可撤回、可审计

AI 直接操作用户的电脑和文件,是企业最敏感的场景。LinkSense 的处理方式:

- **授权在服务端,不在设备上。** 每次运行只发放短时凭证,真实模型密钥不下发到任何终端,模型调用经 LinkSense 网关转发。
- **撤销即时生效。** 停用账号或撤销设备后,新的执行无法开始,进行中的执行在下一次授权检查时被拒绝,正在输出的模型流当场中断。
- **每个动作都留痕。** 工具调用、浏览器操作、外部连接与凭据使用逐条写入审计:谁、在哪个会话、对哪台设备、做了什么、结果如何。
- **不确定时不重试。** 对可能已产生副作用的操作(例如浏览器已提交表单),系统如实标记"结果不确定",绝不自动重放,避免重复发送、重复提交这类事故。
- **只读与写入分级。** 浏览器等高风险操作按协作模式分级放行,只有只读动作可以单独通过。

**客户价值:** IT 敢批准、员工敢用。Agent 的能力边界和撤销手段,第一次达到企业 IT 可以接受的水平。

---

## 能力二:隐私遮蔽 —— 敏感信息不进第三方模型

发送给大模型的文本,在离开 LinkSense 之前先经过脱敏引擎:

- **自动识别并替换:** 私钥、API Key、访问令牌、密码、各类 Secret,以及客户自定义的内部词表(项目代号、客户名单等)。
- **占位符机制:** 模型看到的是 `{{API_KEY_a3f2}}` 这样的占位符;同一段对话中同一敏感值对应同一占位符,不打断模型的推理连贯性。
- **到达用户前还原:** 模型返回内容中的占位符在交付用户前换回原文,用户看到的始终是真实数据。
- **可控可见:** 每类敏感信息可选择"遮蔽"或"仅提醒";提供脱敏统计,让用户知道哪些内容被保护过。
- **配置本身也加密:** 自定义词表可能包含内部信息,因此相关设置以密文存储。

**客户价值:** 让"用 AI"和"敏感数据不进第三方"在制度上可以并存。合规、法务、采购最容易卡住的一关,先解决一半。

## 和常见方案的区别

| | 云端托管的 AI Agent | 本机脚本 / 通用助手 | LinkSense |
| --- | --- | --- | --- |
| 执行位置 | 厂商服务器 | 用户电脑,但没有管控 | 用户自己的电脑 |
| 权限控制 | 厂商账号体系 | 本机系统权限,撤销靠卸载 | 服务端逐次授权,一键撤回 |
| 审计 | 只有厂商日志 | 无 | 每次关键动作留痕 |
| 发给模型的数据 | 原样 | 原样 | 出域前脱敏,占位符替换 |
| 部署方式 | 公有云 | 不可管理 | 支持私有化部署 |

---

## 边界(对外表述请照此口径)

- 脱敏基于规则识别,覆盖常见密钥格式和客户自定义词表,**不承诺"零泄露"**;统一表述为"降低敏感信息外泄面"。
- 模型请求仍会发往企业所配置的模型服务商(脱敏之后),**不改变数据出域路径本身**;私有化模型部署可进一步收敛这一点,以具体交付方案为准。
- 凭据与词表加密依赖部署时配置的主密钥,当前不提供 KMS / HSM 托管或客户自持密钥版本。
- 桌面执行当前支持 macOS,其他平台以实际发布为准。
- 以上为产品能力描述,**不构成 SOC 2 / ISO 27001 等认证声明**。

- 能力一依据:短时运行租约(按连接滑动续期,撤销后立即拒绝)、模型代理转发(真实供应商密钥只存服务端,租约只存 hash)、设备/账号 `auth_valid_after` 双 epoch 失效、连接级 fencing、工具调用逐次鉴权 + 去重、`RUNNER_OPERATION_UNCERTAIN` 不重放、浏览器写操作要求 default 协作模式。代码见 `apps/api/src/modules/desktop-credentials/`、`apps/api/src/modules/desktop-devices/`。
- 能力二依据:规则引擎在 `packages/shared/src/privacy-masking-engine`,脱敏在 runner 的模型网关执行,协议字段有白名单(不会被遮坏)、流式响应逐事件还原、占位符 HMAC 派生、设置 AES-256-GCM 加密。
- **注意:脱敏发生在 LinkSense 网关层,不是终端设备上**,对外不要写"本地脱敏"。
- 不要承诺:全平台、保证不泄露、认证合规、客户自持密钥。长任务租约会续期,不要写"10 分钟自动失效"。
