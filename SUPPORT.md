# Support

- Reproducible defects: Open a GitHub Issue and include the version, deployment type, reproduction steps, and redacted logs.
- Usage questions, solution discussions, and shared experiences: Use GitHub Discussions.
- Security vulnerabilities: Report them privately as described in [SECURITY.md](./SECURITY.md); do not open a public Issue.

Do not upload `.env` files, access tokens, database connection strings, user files, complete logs, or other sensitive information. Open-source community support does not guarantee a fixed response time.
