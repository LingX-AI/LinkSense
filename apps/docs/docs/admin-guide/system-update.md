# 检查并升级 LinkSense

:::info 管理员操作
进入“设置 → 系统更新”。网页只检查并展示版本，不会静默下载或安装更新。
:::

## 查看版本状态

页面自动检查 LinkSense 的 GitHub 正式发布，显示当前版本、最新版本、检查时间、发布时间和发布说明。可以选择“立即检查”刷新结果，或打开 GitHub 发布页核对完整信息。

检查失败不会影响其他业务功能。页面会区分无法连接 GitHub、请求受限和响应无法识别；修复服务器出站网络或等待限制解除后重试。

有新版本时管理员会在主界面看到提示。关闭提示只对当前管理员和当前版本生效，新版本发布后仍会再次显示。

## 升级前准备

1. 阅读从当前版本到目标版本的发布说明。
2. 安排业务低峰维护窗口，并在“系统设置 → 系统维护”通知用户。
3. 确认部署主机磁盘空间、Docker 服务和 PostgreSQL 备份位置可用。
4. 等待或停止不应跨升级继续运行的任务，并确保管理员仍能访问系统健康页。

## 在部署主机执行

Linux：

```bash
curl -fsSL https://raw.githubusercontent.com/LingX-AI/linksense/main/upgrade.sh | sudo sh
```

macOS（不要使用 `sudo`）：

```bash
curl -fsSL https://raw.githubusercontent.com/LingX-AI/linksense/main/upgrade.sh | sh
```

脚本会识别 Core 或 Full 版本，等待运行中的任务结束，并在数据库迁移前创建经过验证的 PostgreSQL 备份。保存脚本输出的备份地址；数据库迁移开始后的失败不会自动回滚数据库。

## 升级后验证

进入“系统健康”确认 API、数据库、Redis、存储、Runner、知识解析与检索等项目恢复；再创建一个最小任务验证执行链路。确认无误后提前关闭维护或等待维护窗口自动结束。

升级失败时保留终端输出和备份地址，由有部署权限的人员按发布说明处理。不要在未确认数据库状态时反复运行升级脚本。
