# 模型与生成能力设置

:::info 管理员操作
进入“设置 → 模型设置”。修改只影响后续新轮次或新文档处理，不改写正在运行和历史记录。
:::

## 模型渠道

每个渠道配置名称、Base URL、API Key、协议兼容模式，再单独添加模型。通过“当前渠道”切换查看模型列表，在渠道的三点菜单中选择“编辑渠道”，打开居中弹窗。API Key 保存后不回显，留空可保留已有密钥。

添加渠道时只需配置连接信息并保存，再通过“添加模型”单独配置模型。尚未添加模型的渠道不会出现在输入框的模型选项中。列表只显示模型名称、类型、价格和对话可选状态，点击编辑按钮打开模型设置弹窗。保存只提交当前弹窗的修改，取消时可以放弃未保存内容。

协议模式包括：

- 原生 Responses：上游完整支持所需 Responses 与工具类型。
- Responses 工具兼容：上游只接受标准 function 工具。
- Chat Completions 转换：上游只提供兼容的 `/chat/completions`。

兼容层只转换协议形状，不代执行工具或重放整个轮次。

## 模型

模型 ID 在全部渠道中唯一。配置显示名称、类型、服务商、图片输入能力、支持推理强度和价格：

- 对话模型：输入、缓存输入和输出单价。
- Embedding 与 Ranker：输入单价。

价格单位为美元/百万 Token。保存时的价格会固化到后续用量事实；调价不重算历史费用。

“模型上下文长度”填写大于 0 的 Token 数；留空时由系统自动探测。该值用于任务中的背景信息窗口用量展示，并让运行环境在接近模型上限前自动压缩上下文。应按服务商和模型真实能力填写，不能把更大的数字当作扩容方式。

只有对话模型显示“对话可选”开关，Embedding 与 Ranker 模型不显示。“对话可选”只控制对话输入框的模型列表，不影响任务自动命名、知识检索、结果重排或图片理解。已配置对话模型时，必须至少保留一个“对话可选”的对话模型；取消默认模型的“对话可选”状态或删除默认模型时，会选择其他“对话可选”模型。

对话模型的“支持的推理强度”可以多选，候选档位为轻量、中、高、超高、最高和极致，并且至少保留一项。“默认推理强度”只能从已勾选档位中选择；取消当前默认档位时，系统自动改为剩余第一项。

## 模型排序

拖动模型左侧的排序手柄，或在行末操作菜单中选择“上移”“下移”，调整当前渠道内的模型顺序。排序手柄也支持键盘：空格选中，上下方向键移动，空格确认，Esc 取消。

通过“渠道操作”菜单中的“上移渠道”“下移渠道”调整渠道顺序。排序调整后自动保存，失败时保留原顺序并显示提示。对话输入框按渠道顺序、渠道内模型顺序展示已开启“对话可选”的对话模型，排序不会改变用户当前选择的模型。

## 对话与任务自动命名模型

模型渠道列表末尾可以分别选择对话默认模型和任务自动命名模型。对话默认模型只允许选择“对话可选”的对话模型；任务自动命名模型可以选择任意已配置的对话模型，不读取部署环境中的内置命名模型。自动命名产生的输入、缓存输入和输出 Token 会单独计入“任务自动命名”用量；供应商未返回用量时显示为估算。

## 记忆提取模型

在模型选择区域，从已配置的对话模型中选择“记忆提取模型”。系统直接使用该模型已有的渠道、凭据和价格，无需重复填写连接信息；“对话可选”开关不影响它用于记忆提取。被引用的模型或渠道需要先解除记忆提取选择，才能删除。

选择“使用当前任务模型”时，每个任务使用自身的模型提取记忆。无论是否选择专用模型，提取均采用该模型已配置的最低受支持推理强度，不改变任务本身的推理强度。此设置只影响提取，整合仍使用当前任务模型。

只有用户主动开启记忆后才会生成记忆。配置更新用于后续启动的任务运行环境，已有记忆不会被清空。记忆状态由用户内的多个任务共享，并由原生引擎根据处理进度、作业锁和输入变化防止重复处理；切换模型或重启不会重置这些状态。失败恢复或历史更新仍可能产生新的模型调用，防重并不等于零重试或费用上限。

## 用户额度

用户额度在独立的[额度管理](./quota-settings.md)页面配置，单位为 credits。

## 知识库检索模型

选择一个已配置的 Embedding 模型，并可选 Ranker 模型。“对话可选”状态不会影响这些系统模型。保存会真实调用服务，验证连接和向量维度。

:::warning 切换 Embedding 模型
切换会立即使全部现有知识库索引失效，检索不可用，直到在“系统健康”完成全量索引重建。先评估维护窗口，再确认切换。
:::

Ranker 未配置或调用失败时，系统使用等权 RRF 结果，不会阻断基础混合检索。

## 文档图片理解

可选择已配置且标记为“支持图片理解”的对话模型；“对话可选”状态不会影响图片理解。保存时会真实探测图片输入、结构化输出和关闭思考能力。配置只影响后续新处理或重建的文档，不改写既有解析内容。

## 语音转文字模型

启用后，普通任务和嵌入应用的麦克风输入会使用这里的服务。选择已开通的服务商，确认 Base URL，填写 API Key 和模型或部署名称；Azure OpenAI 还需要 API 版本。已保存的 API Key 不会回显，编辑时留空会保留原密钥。

可选服务商包括阿里云百炼、OpenAI、OpenAI 兼容服务、Azure OpenAI、Groq、Deepgram、AssemblyAI、ElevenLabs、Rev.ai、Gladia 和 fal.ai。服务商预填值只是连接起点，实际模型、区域、权限和计费以你的服务商账号为准。

保存后使用[语音输入](../user-guide/tasks/voice-input.md)验证一段不含敏感信息的短录音。关闭该设置后，新的语音转文字请求不可用，但普通文字任务不受影响。

## 图片生成模型

启用后，用户可以在任务中调用内置图片生成能力。选择服务商、填写模型和 API Key，并配置单张图片价格；该价格按实际生成张数记录到用量与 credits。Base URL 由服务商自动确定，不在页面中自由修改。

支持阿里云百炼、OpenAI、Google Gemini、Stability AI、fal.ai、Replicate 和 Together AI。阿里云百炼还需要 Workspace ID 与区域。各服务商和模型允许的最大生成张数不同，单次请求最多 10 张；运行时会按当前模型上限截取。

透明背景可以由模型原生生成，或在适合清晰边缘的场景下自动处理。复杂的头发、毛发、玻璃、烟雾、发光和半透明边缘应选择原生支持透明输出的模型。

API Key 保存后不会回显，编辑时留空会保留原密钥。切换服务商时应填写该服务商的新密钥并核对价格。配置后可按[生成图片](../user-guide/tasks/generate-images.md)进行一次单图验证。
