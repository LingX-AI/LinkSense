# 审计日志

:::info 管理员操作
进入“设置 → 审计日志”。审计用于追踪安全和治理事实，不是用户内容浏览器。
:::

## 可以查询的事件

审计区分三个数据范围：

- 永久审计日志：账号与角色、用户组、插件/Skill 导入和发布、凭据生命周期、知识库治理、模型和系统设置，以及管理操作结果。
- 任务执行元数据：跨用户的脱敏执行摘要、状态、能力名称和文件数量，不含标题、正文或下载入口。
- 已删除任务产物：永久保留产物的数量、大小、校验状态和删除时间，不提供内容查看、恢复或下载。

使用页面筛选条件按时间、操作者、目标类型、动作或结果缩小范围。任务执行元数据还可按插件、Skill、错误码、Runner 状态、归档状态及创建/运行日期筛选。选择记录可在详情抽屉查看稳定动作、必要 ID、时间和结构化脱敏元数据；界面不会把协议原始字段直接暴露为用户内容。

## 内容边界

管理员审计不会显示：

- 其他用户任务正文、附件或成果内容。
- 完整工具参数或第三方原始响应。
- 密码、Token、API Key、凭据明文。
- 完整 Base URL、连接串或内部路径。

某些记录保留来源 IP 和 User-Agent 作为受限审计元数据；界面按安全策略展示，不用于普通用户查询。

## 被拒绝的操作

自我停用、降级自己、尝试停用最后一个管理员、越权读取和无效治理请求也会记录结果与稳定错误码。被拒绝记录有助于区分误操作和异常尝试。

## 使用建议

- 先限定时间范围，再按目标或动作筛选。
- 导出或转述时继续遵循组织的数据最小化政策。
- 将审计事实与系统健康时间点结合排查，不要把缺少正文误认为记录不完整。
- 审计记录是永久安全历史；业务父实体删除后仍保留最小 ID、类型和影响数量。
