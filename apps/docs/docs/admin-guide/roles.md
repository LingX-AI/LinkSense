# 角色与权限边界

:::info 管理员操作
“设置 → 角色与权限”是只读权限概览。当前版本不支持创建或编辑自定义角色。
:::

## 固定角色

LinkSense 只有两个角色：

- 普通用户：创建和管理自己的任务、个人能力与知识库，使用被授予的资源。
- 管理员：在普通用户能力基础上访问用户、用户组、插件中心治理、知识库治理、模型、设置、健康、审计和用量页面。

不存在超级管理员、部门管理员、只读管理员或自定义权限组合。初始化创建的首个管理员没有额外隐含权限。

## 角色不等于内容访问

管理员角色提供治理权限，但不会自动授予其他用户任务、个人能力正文或知识库文档内容的访问。内容读取仍由所有权与分享关系决定。

## 修改角色

在用户管理中修改其他用户角色。降级管理员前确认系统仍有至少一个启用管理员。

管理员不能：

- 降低自己的角色。
- 停用自己。
- 降级或停用最后一个启用管理员。

服务端会在事务内执行检查，即使两个管理员同时操作也不能绕过。

## 用户组与角色

用户组只用于扁平成员关系和资源授权，不继承或改变角色。把用户加入某个组不会使其成为管理员。
