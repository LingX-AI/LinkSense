# 用量与费用统计

:::info 管理员操作
进入“设置 → 用量统计”。该页面用于观察资源事实，额度请在“额度管理”中设置。
:::

用户 credits 额度在[额度管理](./quota-settings.md)中配置，已有用户额度在“用户组与用户 → 用户”中调整。

## 时间范围

选择全部时间、最近 7 天、最近 30 天，或自定义开始和结束日期。趋势会根据范围自动按日、月或年汇总。

## 统计视图

- 全局：任务、实际轮次、模型调用、总 Token 和总费用。
- 工作负载：AI 回答、文档嵌入、检索嵌入和结果重排。
- 模型：类型、采集方式、调用、轮次、Token 分项和费用。
- 应用：按任务创建时关联的应用汇总任务、轮次、模型调用、Token、费用及逐模型明细；未通过应用创建的用量进入“未关联应用”。
- 用户组：按查询时有效成员关系覆盖成员数据。
- 用户：启用或停用用户的用量、当前组和逐模型明细。

Token 使用 K、M、B 缩写，任务、轮次、调用和成员数显示完整整数。

## 计数口径

- 任务在创建时记录一次不可变活动事实。
- 轮次只统计真实创建的执行轮次；草稿、排队、重连和重复事件不重复计数。
- 原生累计 Token 快照按增量去重。
- 外部嵌入和重排优先使用可信 usage；没有时只对实际输入估算并标记。

## 费用

费用使用调用发生时的模型单价快照计算，币种为人民币。缓存输入是输入子集，推理输出是输出子集，不重复计费。

- 后续调价不重算历史。
- 0 元是有效价格。
- 无可靠历史价格的 Token 计入“未定价 Token”，不会用当前价格补算。

## 用户组注意事项

一个用户属于多个组时会计入每个组，因此组行不能相加推导全局总量。没有有效组关系的用户进入“未分组用户”。

## 排序与导出

明细表可以按页面提供的列排序。导出 CSV 会使用当前时间范围和筛选口径生成管理数据；导出前再次确认范围，并按组织政策保存和传递文件。导出不会包含提示词、回复正文、文件内容或凭据。

## 数据保留

任务硬删除后，任务、轮次、模型调用、Token、费用和应用归属事实仍保留。记录不包含提示词、回复正文、文件内容、凭据、Base URL 或 API Key。
