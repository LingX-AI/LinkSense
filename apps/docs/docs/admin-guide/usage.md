# 用量、费用与账单

:::info 管理员操作
进入“设置 → 用量统计”。“用量统计”标签页用于观察资源事实，“账单”标签页用于查看已结算的自然月模型账单；额度仍在“额度管理”中设置。
:::

用户 credits 额度在[额度管理](./quota-settings.md)中配置，已有用户额度在“用户与用户组 → 用户”中调整。

## 时间范围

选择全部时间、最近 7 天、最近 30 天，或自定义开始和结束日期。趋势会根据范围自动按日、月或年汇总。

## 统计视图

- 全局：任务、实际轮次、模型调用、总 Token 和总费用。
- 工作负载：AI 回答、任务自动命名、记忆生成、文档向量化、检索查询向量化、结果重排和图片生成。
- 模型：生成、嵌入、重排和图片模型的采集方式、调用、轮次、Token 分项和费用。
- 应用：按任务创建时关联的应用汇总任务、轮次、模型调用、Token、费用及逐模型明细；未通过应用创建的用量进入“未关联应用”。
- 用户组：按查询时有效成员关系覆盖成员数据。
- 用户：启用或停用用户的用量、当前组和逐模型明细。

Token 使用 K、M、B 缩写，任务、轮次、调用和成员数显示完整整数。

## 计数口径

- 任务在创建时记录一次不可变活动事实。
- 轮次只统计真实创建的执行轮次；草稿、排队、重连和重复事件不重复计数。
- 原生累计 Token 快照按增量去重。
- 外部嵌入和重排优先使用可信 usage；没有时只对实际输入估算并标记。

## 费用

费用使用调用发生时的模型单价快照计算，币种为美元。缓存输入是输入子集，推理输出是输出子集，不重复计费。

- 后续调价不重算历史。
- 0 美元是有效价格。
- 无可靠历史价格的 Token 计入“未定价 Token”，不会用当前价格补算。

## 用户组注意事项

一个用户属于多个组时会计入每个组，因此组行不能相加推导全局总量。没有有效组关系的用户进入“未分组用户”。

## 排序与导出

明细表可以按页面提供的列排序。“导出 Excel”会使用当前时间范围和筛选口径生成多工作表文件，包含摘要、趋势，以及模型、用途、应用、用户组和用户等当前报表维度及其明细。导出前再次确认范围，并按组织政策保存和传递文件。导出不会包含提示词、回复正文、文件内容或凭据。

## 月度账单

切换到“账单”标签页，可以查看本月账期和已经生成的月度账单。账单按系统时区的自然月结算，在月份结束后自动生成；本月卡片会显示预计生成时间。服务恢复或升级后也会补齐缺失的已结束月份。

月度账单是按模型汇总的不可变费用快照，包含输入、缓存输入、输出、总 Token、计价方式和金额：

- 同一模型整月使用一种价格时显示对应的每百万 Token 单价；月内发生调价时标记为“月内多种单价”。
- 没有可靠价格快照的 Token 显示为未计价，不会补用当前价格。
- 账单只按模型汇总，不包含提示词、回复、文件内容、用户明细或额度设置。
- 已生成账单不会因后续调价、任务删除或成员关系变化而重算。

选择一份账单可以在线查看模型明细，或按当前界面语言导出 PDF。导出操作会写入审计日志；下载后应按组织的账单和财务资料保留规则保存。

## 数据保留

任务硬删除后，任务、轮次、模型调用、Token、费用、应用归属事实和已经生成的月度账单仍保留。记录不包含提示词、回复正文、文件内容、凭据、Base URL 或 API Key。
