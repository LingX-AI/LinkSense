# 管理员指南概览

本指南可由所有人阅读，但 LinkSense 中的管理页面和操作只向“启用状态的管理员”开放。

:::info 管理员操作
管理员入口位于“设置”的“管理”分组。服务端会对每个管理请求重新校验角色和状态，隐藏菜单不是权限边界。
:::

## 管理范围

| 页面 | 主要职责 |
| --- | --- |
| 用户组与用户 | 创建账号、导入用户、启停账号、维护扁平用户组 |
| 角色 | 查看普通用户与管理员的固定权限边界 |
| 插件中心 | 审核发布、停用或恢复风险上架项 |
| 知识库 | 跨用户治理元数据、状态和所有权 |
| 知识库数据源 | 配置 SharePoint 等外部连接 |
| 模型设置 | 管理模型渠道、模型、价格和知识检索模型 |
| 系统设置 | 管理产品与认证能力设置 |
| 系统健康 | 查看依赖状态、执行运行量、容器资源与清理失败项 |
| 用户反馈 | 查看用户主动提交的文字和问题截图 |
| 审计日志 | 查询永久事件、任务执行元数据和已删除任务产物摘要 |
| 用量统计 | 分析任务、轮次、模型、Token 和费用 |
| 系统更新 | 检查正式版本并按安全流程升级部署 |

## 管理员看不到什么

管理员权限不会自动提供：

- 其他用户的任务正文、附件内容或成果下载。
- 其他用户的个人插件/Skill 正文。
- 知识库文档正文、原文预览或下载，除非管理员本身通过所有权或分享获得访问。
- 密码、Token、API Key、连接串或加密秘密明文。

## 首次初始化

未初始化的全新部署会显示初始化向导，用于创建首个本地管理员。该账号与后续管理员使用相同角色，不是超级管理员。初始化完成后不会再次开放向导。

## 操作原则

- 先确认影响范围，再执行停用、删除、转移或模型切换。
- 对不可逆操作保留业务确认记录。
- 使用审计日志验证管理结果，不要依赖浏览器本地状态。
- 发现基础设施异常时在系统健康页确认，再由有部署权限的人员处理环境配置。
