# 知识库治理

:::info 管理员操作
进入“设置 → 知识库”。页面提供跨用户治理元数据，不自动授予文档正文、预览或下载权限。
:::

## 查找知识库

按名称或所有者搜索，并按生命周期、可用状态和来源查看。列表展示安全元数据、文档与容量汇总，不返回文档内容。

## 可用治理操作

- 停用或启用：控制所有用户后续新任务是否可以使用。
- 归档：把知识库变为只读。
- 永久删除：只允许删除已归档知识库，操作不可撤销。
- 重试失败清理：重新处理资源清理任务。
- 撤销访问：移除指定授权来源。
- 转移所有者：选择其他启用用户。

需要填写原因的操作会把原因写入脱敏审计。删除仍需在归档后单独确认。

## 所有者被停用

知识库继续保留，既有接收方仍按权限使用。被停用所有者不能维护；管理员可停用知识库或把所有权转移给有效用户。

## 检索与索引异常

单个文档失败由所有者在知识库中重试。部署范围的嵌入维度变化或索引失效应在“系统健康”执行全量重建，而不是逐个修改用户知识库。

## 权限边界

治理动作必须与内容访问分开。若管理员需要查看文档，应由所有者按正常分享流程授予访问；不要使用治理接口绕过。
