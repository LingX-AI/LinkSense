# 用户管理

:::info 管理员操作
进入“设置 → 用户组与用户 → 用户”。LinkSense 不开放自助注册。
:::

## 创建用户

手动创建时填写姓名、唯一邮箱、角色和可选用户组。新用户没有本地密码，系统不会自动发送邀请。

用户可以：

- 使用已配置的 SSO 或 Teams 登录。
- 在登录页通过邮件流程首次设置本地密码。

管理员不能为用户设置、查看、导入或重置密码。

## Excel 批量导入

下载页面模板，填写姓名、邮箱、角色和用户组后上传。导入会校验：

- 必填字段。
- 邮箱格式与全局唯一性。
- 角色是否合法。
- 用户组是否已存在。

模板不包含密码字段。错误行会返回可读反馈；修正后重新导入。

## 编辑用户

可修改姓名、邮箱、角色和用户组。修改邮箱会立即撤销该用户全部会话和未使用的设密/重置链接，用户需要使用新邮箱重新登录。

## Token 用量

编辑已有用户时，可以设置个人 Token 用量：

- 周用量：用于判断该用户本周能否发起新任务。
- 月用量：用于判断该用户本月能否发起新任务。
- 单位为百万 Token，可以填写大于 0 的数字和最多 6 位小数。
- 留空表示不设置个人用量。

当前周期用量剩余为 0 后，用户暂时不能发起新任务，需要等下个周期重置。已经运行中的任务不受影响。

在用户列表中勾选多个用户后，可以使用“批量设置用量”同时更新周用量和月用量。批量操作中未勾选的用量字段会保持不变；勾选后留空表示清除该字段的个人用量。

:::tip 新用户初始用量
如果希望新建或导入用户时自动带上用量设置，请先在“设置 → 模型设置 → 用户初始 Token 用量”中配置默认周/月用量。修改初始用量不会影响已有用户。
:::

当前版本不支持删除用户账号。需要阻止访问时使用停用。

## 停用与恢复

停用后：

- 禁止新登录，现有会话在下一次请求时失效。
- 不能创建、继续任务或下载成果。
- 尚未启动的后续请求会被取消。
- 已运行轮次继续到原生终态，不会被伪造为中断。
- 历史任务、知识库、发布和审计保留。

恢复后用户可重新登录并访问自己的历史内容，被取消的排队请求不会自动恢复。

## 管理员保护

- 管理员不能停用自己或降低自己的角色。
- 系统必须始终保留至少一个启用管理员。
- 对其他管理员操作时仍会在事务内重新检查此规则。

被拒绝的高风险尝试也会写入审计日志。
