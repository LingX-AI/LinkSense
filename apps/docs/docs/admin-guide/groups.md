# 用户组管理

:::info 管理员操作
进入“设置 → 用户组与用户 → 用户组”。用户组用于批量授予插件或知识库相关访问，不代表部门层级。
:::

## 结构规则

- 用户组是扁平结构，不支持父子组。
- 一个用户可以属于多个用户组。
- 名称必须在系统内唯一。
- 用户组本身不改变普通用户或管理员角色。

## 创建和编辑

填写名称与可选说明。创建后添加一个或多个现有用户。成员加入和移除都会记录操作者与时间。

日常移除成员采用撤销状态，保留必要历史。用户后续可能仍通过其他用户组或个人授权访问同一知识库。

## 查看成员

用户列表最多紧凑显示部分组名，完整成员关系可在组详情和悬浮说明中查看。不要通过单个列表标签推断用户只有一个组。

## 删除用户组

删除是不可恢复操作。系统会在同一事务内清理该组的有效及已撤销成员关系、知识库授权，避免孤儿数据。永久审计只保留组 ID、受影响记录类型和数量等最小元数据。

删除前检查：

1. 哪些用户通过该组获得知识库访问。
2. 是否需要先建立替代组或个人分享。
3. 用量统计中的历史组维度解释是否会受当前成员关系变化影响。

## 与用量统计的关系

“按用户组”统计根据查询时的有效成员关系覆盖当前成员。一个用户属于多个组时会计入每个组，因此不能把各组行相加推导全局总量。
