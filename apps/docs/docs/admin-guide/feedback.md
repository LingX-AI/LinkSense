# 管理用户反馈

:::info 管理员操作
进入“设置 → 用户反馈”。普通用户可以在“我的反馈”查看自己的反馈和回复，不能查看其他人的内容。
:::

## 查看反馈

列表按页显示提交用户、正文摘要、图片数量、回复状态和提交时间。选择“查看”可阅读完整正文并打开图片预览；图片加载失败时刷新页面再试，不要要求用户通过不受控渠道发送敏感原图。

反馈可能包含用户主动提交的业务信息。只为问题定位使用，避免复制到日志、公开任务或无关外部服务。反馈页不是审计日志，也不自动关联具体任务执行记录。

## 回复用户

打开反馈详情，在“回复用户”中输入文字或添加图片后选择“发送回复”。支持纯文字、纯图片和图文回复；每次最多 2,000 个字符、9 张图片，每张不超过 5 MB，支持 PNG、JPEG、WebP 和 GIF。也可以直接粘贴图片。

同一条反馈可多次回复，回复按时间排列。发送失败时草稿和所选图片会保留。成功发送后，用户可在“我的反馈”查看回复；列表状态变为“已回复”，不自动表示问题已解决。

## 删除反馈

删除会永久移除反馈正文、所有回复及其全部图片，无法恢复。确认已经完成必要处理并符合组织保留要求后再删除。删除反馈不会删除提交用户、任务、审计记录或用量事实。

## 处理建议

- 优先使用用户提供的发生时间、页面和稳定错误码定位问题。
- 需要更多信息时通过组织认可的沟通渠道联系提交者。
- 不要索取密码、Token、API Key、二维码或一次性链接。
- 涉及系统故障时结合[系统健康](./health.md)和[审计日志](./audit.md)核对。
