# 管理用户反馈

:::info 管理员操作
进入“设置 → 用户反馈”。普通用户只能提交反馈，不能查看反馈列表或其他人的内容。
:::

## 查看反馈

列表按页显示提交用户、正文摘要、图片数量和提交时间。选择“查看”可阅读完整正文并打开图片预览；图片加载失败时刷新页面再试，不要要求用户通过不受控渠道发送敏感原图。

反馈可能包含用户主动提交的业务信息。只为问题定位使用，避免复制到日志、公开任务或无关外部服务。反馈页不是审计日志，也不自动关联具体任务执行记录。

## 删除反馈

删除会永久移除反馈正文和全部图片，无法恢复。确认已经完成必要处理并符合组织保留要求后再删除。删除反馈不会删除提交用户、任务、审计记录或用量事实。

## 处理建议

- 优先使用用户提供的发生时间、页面和稳定错误码定位问题。
- 需要更多信息时通过组织认可的沟通渠道联系提交者。
- 不要索取密码、Token、API Key、二维码或一次性链接。
- 涉及系统故障时结合[系统健康](./health.md)和[审计日志](./audit.md)核对。
