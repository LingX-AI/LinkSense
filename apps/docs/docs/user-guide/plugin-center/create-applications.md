# 创建和管理应用

应用为重复场景提供受控入口。创建者可以组合模型、指令、插件、Skill、知识库和 MCP，再在组织内共享；应用不会扩大创建者或使用者原本没有的资源权限。

## 创建普通应用

1. 进入“插件中心 → 应用 → 我创建的”。
2. 选择“创建应用 → 创建普通应用”。
3. 填写名称、说明并选择内置图标或上传图片。
4. 决定固定模型和推理强度，或允许用户在聊天中选择。
5. 填写应用指令，并选择由你管理的插件、Skill、知识库和 MCP。
6. 保存后先使用“立即试用”验证完整流程。

应用指令不会向被共享者展示。插件会使用创建者已绑定的插件凭据；MCP 工具可能产生外部副作用，添加前必须确认用途和权限。

## 导入交互式应用

选择“导入交互式应用”，上传根目录含 `manifest.json` 和 `index.html` 的 ZIP 包。页面在隔离 iframe 中运行，并通过 LinkSense SDK 启动任务或控制原生聊天区。完整包结构和接口见[开发交互式应用](../../developer-guide/interactive-application.md)。

更新交互式应用包时，Manifest 版本必须递增。新任务使用新版本；历史任务固定使用创建时的包版本。

## 更新、停用与删除

- 编辑配置后，所有人的后续新轮次读取最新资源组合；已经运行和历史轮次不被改写。
- 停用后不能开始新任务，既有任务记录仍保留。
- 必需依赖被停用、删除或失去权限时，应用会显示不可用，修复依赖后再启用或试用。
- 删除应用后不再出现在插件中心，也不能开始新任务；既有个人任务不会随应用删除。

发布给组织前，继续完成[共享与外部访问](./application-access.md)和[应用用量](./application-usage.md)检查。
