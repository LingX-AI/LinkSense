# 使用组织应用

组织应用把模型、插件、Skill、知识库和固定指令组合成一个受管理入口，适合标准化工作流程。

应用分为普通应用和交互式应用。交互式应用会打开开发者提供的业务界面，并在右侧分栏显示 LinkSense 原生聊天。拖动两个区域之间的分隔线可以调整聊天宽度；你也可以隐藏或重新显示聊天区，任务和应用中的数据不会因此停止或丢失。

## 找到应用

进入“插件中心 → 应用”，在公开范围中搜索应用。详情会说明应用创建者、用途以及由应用固定的资源。

## 启动应用任务

选择应用后创建任务，并按应用页面填写请求。根据应用配置：

- 模型可能由创建者固定，也可能由你选择。
- 插件、Skill、知识库和应用指令由创建者维护。
- 应用知识库只在应用任务中用于检索，不因此授予你浏览、预览、下载或管理知识库的权限。

应用配置会在每个新轮次开始时重新获取。创建者完成共享更新后，新任务和已有任务的下一次执行使用最新共享版本；从应用中心使用的应用以当前已审核上架的版本为准。草稿编辑不会改变共享版本；创建者确认“发布更新”或成功更新应用包后，共享版本自动更新。正在运行的轮次和历史结果不被改写。

交互式应用任务会一直保留在左侧任务列表中。即使你切换到其他任务、刷新页面或关闭后重新进入，LinkSense 也会打开该任务当前记录的应用版本，恢复此前已经产生的结构化数据，并继续接收后续结果；这不会重新执行任务，也不会单因打开页面就切换到新版本。已有任务在下一次执行时才采用对应入口的最新已发布版本，之后重新进入会打开该任务已采用的版本。

## 应用不可用

应用被停用或其必需模型、能力、凭据、知识库不可用时，不能开始新任务。既有个人任务记录仍保留。可联系应用创建者或管理员处理依赖。

如果需要创建或维护入口，参见[创建和管理应用](./create-applications.md)；组织共享和 iframe 访问分别由[共享应用与配置外部访问](./application-access.md)说明。

## 创建者查看用量

应用创建者可以打开应用卡片的“更多操作 → 用量统计”，按全部时间、最近 7 天、最近 30 天或自定义日期查看使用人数、任务数、轮次数、模型调用、Token 和费用。统计页同时提供趋势、Token 与费用构成以及按模型和用途汇总的明细，但不会向创建者展示使用者姓名或邮箱。

Token 和费用只覆盖系统开始采集后的调用。任务和轮次可以包含更早的历史记录，但系统不会使用当前模型价格推算更早的 Token 或费用；没有可靠价格快照的 Token 会明确标记为未定价。

指标口径和范围选择见[查看应用用量](./application-usage.md)。

## 与普通任务的区别

普通任务由你逐轮选择资源；组织应用由创建者维护一个受控组合。不要把应用入口当作额外权限来源，所有资源访问仍由 LinkSense 在服务端校验。
