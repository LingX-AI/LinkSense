# 管理插件凭据

插件凭据用于保存 API Key、Token 或其他只应由你的插件使用的秘密。凭据明文只在提交时发送，保存后不会再次显示。

## 新增凭据

1. 进入“设置 → 插件凭据”。
2. 选择“新增凭据”。
3. 填写不含敏感内容的名称和提供方类型。
4. 添加一个或多个密钥字段并输入值。
5. 保存。

LinkSense 会加密保存内容。编辑时留空表示保留已有密文；输入新值会替换相应内容。

## 绑定到插件

凭据不会仅凭类型自动注入。选择“绑定到插件”，指定：

- 目标插件。
- 凭据。
- 与插件声明完全一致的配置 key。

一个插件配置 key 必须能唯一确定一个有效个人凭据。缺失绑定或存在冲突时，任务启动前检查会阻止执行。

## 启用、停用与删除

- 停用：保留绑定，但新的轮次不再使用。
- 启用：满足权限和绑定规则的新轮次可以再次使用。
- 解除绑定：后续轮次不再通过该关系注入。
- 删除：永久删除密文及全部绑定，无法恢复。

## 安全边界

凭据只属于你，不会回退到其他用户或平台凭据。LinkSense 不在任务工作区、插件目录、Skill 目录、日志、审计或界面中显示明文。通用 shell 和 Skill 脚本不能直接继承插件凭据。
