# 用户指南概览

LinkSense 以“任务”为核心。你可以在一个任务中持续对话、补充文件和要求，选择插件、Skill 与知识库，并下载生成的成果。

## 主要入口

| 入口 | 用途 |
| --- | --- |
| 新任务 | 提交问题或工作要求，选择模型和所需能力 |
| 自动化 | 按小时、天、周、月或年定时启动任务 |
| 插件中心 | 发现、安装、更新和管理插件、Skill 与组织应用 |
| 知识库 | 创建资料库、上传文档、共享并用于任务检索 |
| 设置 | 管理语言、资料、个性化、外观、安全、凭据和 MCP |

## 推荐上手顺序

1. 完成登录并确认界面语言。
2. 创建第一个任务，观察执行状态和结果。
3. 根据需要添加文件、插件、Skill 或知识库。
4. 在任务中继续补充要求，下载最终成果。
5. 对重复工作创建自动化。

## 你的数据范围

- 你只能查看自己的任务及其附件、消息和成果。
- 共享给你的知识库可以检索和查看，但只有所有者可以管理文档与共享设置。
- 个人插件、Skill、凭据和 MCP 只用于你的任务。
- 管理员可以治理账号、平台能力和系统配置，但管理员审计界面不提供其他用户任务正文或文件内容。
