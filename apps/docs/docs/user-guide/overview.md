# 用户指南概览

LinkSense 以“任务”为核心。你可以在一个任务中持续对话、补充文件和要求，选择插件、Skill 与知识库，并下载生成的成果。

## 主要入口

| 入口 | 用途 |
| --- | --- |
| 新任务 | 提交问题或工作要求，选择模型、计划/目标模式和所需能力 |
| 自动化 | 按小时、天、周或月在一个固定任务中重复执行工作 |
| 插件中心 | 发现、安装、更新和管理插件、Skill、MCP 与应用 |
| 资料库 | 管理知识库、集中查看任务产物，并发布和维护公开站点 |
| 设置 | 管理语言、资料、个性化、消息渠道、安全、凭据和 MCP |
| 反馈与帮助 | 提交问题反馈，并打开当前页面对应的帮助说明 |

“资料库”的图标是几本竖立的书。其中，“知识库”标签页用于管理和共享可检索的文档，“任务产物”标签页用于集中查看任务生成的文件，“我的站点”标签页用于管理从 HTML 成果发布的公开网页。

## 推荐上手顺序

1. 完成登录并确认界面语言。
2. 创建第一个任务，观察执行状态和结果。
3. 根据需要添加文件、插件、Skill 或知识库，也可以要求生成图片。
4. 从执行动态和任务概览查看进度、成果与外部来源。
5. 在任务中继续补充要求；历史变长时查看背景信息窗口并压缩上下文。
6. 对复杂工作先使用计划模式；需要尝试不同方向时从历史回复创建分支。
7. 对重复工作创建自动化，或把稳定流程创建为应用并共享。

## 你的数据范围

- 你只能查看自己的任务及其附件、消息和成果。
- 共享给你的知识库可以检索和查看，但只有所有者可以管理文档与共享设置。
- 个人插件、Skill、凭据和 MCP 只用于你的任务。
- 管理员可以治理账号、平台能力和系统配置，但管理员审计界面不提供其他用户任务正文或文件内容。
