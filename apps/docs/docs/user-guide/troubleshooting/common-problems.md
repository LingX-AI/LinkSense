# 常见问题排查

## 页面无法登录

- 确认使用正确登录方式，账号已启用。
- 本地密码失败可申请重置。
- 单点登录失败时返回登录页重新发起。
- 多次失败后等待登录保护冷却，不要持续重试。

## 任务不能启动

检查页面的启动前提示：

- 模型已停用或不存在：重新选择模型。
- 插件或 Skill 不可用：移除、更新或联系管理员。
- 必需凭据缺失或冲突：在“设置 → 插件凭据”修复显式绑定。
- 必需 MCP 连接失败：测试连接、地址、认证与超时。
- 知识库不可用：重新选择仍有权访问且状态正常的知识库。
- Credits 额度已达上限：等待下周自动重置，或联系管理员调整、手动重置周额度。

## 任务执行中断

刷新页面并重新进入同一任务，LinkSense 会尝试恢复原轮次。不要因为网络断开连续重复发送相同请求。确定轮次已经失败后再修正问题并重试。

如果提示背景信息窗口超限，普通任务会自动尝试继续一次。最终仍失败时，等待任务停止后使用“压缩上下文”，再说明从哪里继续。完整说明见[草稿与上下文管理](../tasks/context-and-drafts.md)。

计划方案无法确认时，先检查任务是否已经进入新轮次、目标或自动化状态；旧方案操作不会覆盖较新的状态。任务分支失败时，确认原任务已经停止、没有排队请求且未归档。

## 文件上传或预览失败

- 检查类型、大小和批次数量是否符合页面限制。
- 文件扩展名必须与真实内容匹配。
- 预览失败不一定代表原文件丢失；尝试下载原件。
- 知识库文档失败时查看具体处理阶段并选择重试。

## 搜索没有结果

帮助中心本地搜索在静态生产构建中可用；开发模式不生成索引。任务搜索与知识库搜索只返回当前账号有权访问的内容。

## 站点无法发布或访问

- 只有已登记且可下载的 HTML 任务成果可以发布；普通附件或仍在生成的文件不能发布。
- 页面缺少样式、脚本或图片时，回到原任务重新生成并登记完整网页成果，不要只上传入口 HTML。
- 链接名称冲突时换一个 3–80 位的英文、数字或连字符组合。
- 已取消发布、来源任务被永久删除或所有者账号被停用时，公开链接不可访问。
- 更新未发布的站点不会自动恢复公开访问；完成更新后还需在“资料库 → 我的站点”中选择“重新发布”。

完整操作和安全边界见[发布和管理站点](../tasks/publish-websites.md)。

## 飞书机器人没有响应

- 确认“设置 → 消息渠道”中的飞书状态已经连接；等待管理员审核时无需重复扫码，批准后会自动恢复。
- 仅支持机器人创建者发送的一对一私聊文本；群聊、其他成员和非文本消息不会启动任务。
- 本地部署不需要公网回调，但 LinkSense 所在环境必须能访问飞书的 HTTPS 和 WebSocket 服务。
- 如果飞书提示应用不存在，使用“创建新应用”入口替换已删除的应用，不要继续扫描旧二维码。
- 如果出现未命名任务但一直没有启动，请刷新任务和消息渠道状态，再发送一条新的简短文本，不要连续重复原消息。

连接、审核、断开和恢复步骤见[连接和使用飞书](../message-channels/feishu.md)。

## 微信没有响应

- 确认“设置 → 消息渠道”中的微信状态为“在线”。
- 消息必须来自扫码账号本人，并且是当前支持的文本或可转写语音。
- 二维码、手机确认或配对码任一步骤未完成时，重新连接并按最新页面继续。
- 检查 credits 额度、维护状态和任务并发限制，不要连续重复发送相同消息。

完整连接和断开步骤见[连接和使用微信](../message-channels/weixin.md)。

企业微信、钉钉和 Microsoft Teams 的连接条件不同，先从[消息渠道概览](../message-channels/overview.md)进入对应指南。只有 Teams 需要公网 HTTPS 消息接收地址。

## 图片无法生成

- 确认管理员已启用图片生成模型。
- 服务商拒绝时检查提示词、模型和密钥配置；服务不可用时稍后再试。
- 透明背景可能需要当前模型原生支持，尤其是头发、玻璃或烟雾等复杂边缘。
- 如果结果登记或用量记录失败，不要立即重复生成；服务商可能已经处理并计费。

详见[生成图片](../tasks/generate-images.md)。

## 什么时候联系管理员

出现系统健康、模型服务、认证邮件、知识库解析/检索或 runner 不可用提示时，请提供：

- 发生时间和所在页面。
- 页面显示的稳定错误信息或错误码。
- 可安全复现的操作步骤。

不要提供密码、Token、API Key、临时下载链接或敏感文件内容。
