# 创建与管理自动化

自动化会按指定周期发起新的任务轮次，适合日报、周报、定期检查和重复汇总。

## 创建自动化

1. 从侧边栏进入“自动化”。
2. 选择“新建自动化”。
3. 填写标题和每次执行的指令。
4. 选择目标：
   - 固定任务：从已置顶任务中选择，保留连续上下文。
   - 新任务：每次创建独立任务。
5. 选择小时、天、周、月或年周期并填写时间。
6. 确认页面显示的时区和下次执行时间，然后保存。

每月不存在的日期会被跳过，例如选择 31 日时，不会在没有 31 日的月份执行。

## 暂停、恢复和编辑

- 暂停后不会产生新的定时执行，既有任务不受影响。
- 恢复后按当前时间重新计算后续计划。
- 编辑会更新未来执行，不改写历史轮次。
- 删除自动化只删除计划，关联任务和历史内容会保留。

## 查看结果

自动化完成或失败后，侧边栏通知入口会显示状态。打开通知可进入对应任务；查看后未读状态消失。

## 使用建议

- 指令应能够在无人补充信息的情况下独立执行。
- 固定任务必须保持置顶，便于自动化选择和长期跟踪。
- 对依赖外部插件、凭据或知识库的自动化，确保相关能力持续启用。
- 定期检查失败记录；权限、凭据或模型变化可能阻止后续执行。
