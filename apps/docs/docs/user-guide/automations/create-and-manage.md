# 创建与管理自动化

自动化会按指定周期在一个固定任务中发起新轮次，适合日报、周报、定期检查和重复汇总。

## 从建议开始

自动化首页会提供“每日简报”“每周回顾”和“跟进监控”等建议。选择一项会打开新建表单，并预填标题、指令、新建目标任务和建议的每周执行日期与时间。建议只是可编辑模板；保存前应检查数据来源、指令、日期、时间、时区、模型和推理强度是否符合实际需要。

部分建议会引用日历或电子邮件。只有当前账号已经安装并授权对应能力时，自动化才能读取这些数据；否则请先配置能力，或修改模板，避免让无人值守的执行停在授权或补充信息步骤。

## 创建自动化

1. 从侧边栏进入“自动化”。
2. 选择“新建自动化”。
3. 填写标题和每次执行的指令。
4. 选择目标：
   - “现有任务”：从当前账号已置顶的有效任务中选择。
   - “新建任务”：保存自动化时只创建一次任务并自动置顶，后续触发持续复用它。
5. 选择每小时、每天、每周或每月，并设置 1–999 的间隔：
   - 每小时：选择每个周期的第 0–59 分钟；
   - 每天：选择执行时间；
   - 每周：选择至少一个星期和执行时间；
   - 每月：选择日期和执行时间。
6. 确认页面显示的设备时区。保存后系统会统一换算执行时间。
7. 按需设置到期日期。到期日当天仍可执行，次日起停止。
8. 按需开启“指定模型和推理强度”；不开启时使用账号的当前默认设置。
9. 保存并检查页面显示的下次执行时间。

每月不存在的日期会被跳过，例如选择 31 日时，不会在没有 31 日的月份执行。

## 查看与立即执行

自动化列表可以筛选“全部”“已开启”或“已暂停”，并显示上次和下次执行时间。选择“打开任务”可查看完整过程与成果。

选择“立即执行”会绕过定时等待：目标任务空闲时立即开始，正在运行时加入该任务队列。立即执行不会改变后续定时计划。

自动化完成或失败后，侧边栏通知入口会显示状态。打开通知可进入对应任务；查看后未读状态消失。

## 暂停、恢复、编辑和删除

- 暂停后不会产生新的定时执行，既有任务不受影响。
- 恢复后按当前时间和已保存周期计算后续计划。
- 编辑会更新未来执行，不改写历史轮次。
- 删除自动化只删除计划，关联任务和历史内容会保留。

## 使用建议

- 指令应能够在无人补充信息的情况下独立执行。
- 自动化目标任务应保持置顶且有效；取消置顶或归档前，先调整关联自动化。
- 对依赖外部插件、凭据或知识库的自动化，确保相关能力持续启用。
- 定期检查失败记录；权限、凭据或模型变化可能阻止后续执行。
