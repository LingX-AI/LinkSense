# 提交反馈

## 提交步骤

1. 在 LinkSense 侧边栏选择问号按钮“反馈与帮助”。
2. 选择“反馈”。
3. 描述发生页面、操作步骤、期望结果和实际结果。
4. 按需添加截图，也可以把图片直接粘贴到反馈输入框。
5. 检查内容后选择“提交”。

反馈正文最多 2,000 个字符。页面会显示最多图片数量和单张大小限制；支持 PNG、JPEG、WebP 和 GIF。图片不符合格式、体积或数量要求时不会提交。

## 提交哪些信息

建议包含发生时间、可重复步骤、可见错误码和影响范围。不要提交密码、Token、API Key、一次性链接、二维码、完整客户数据或无关敏感截图。

## 提交后的处理

提交成功只表示反馈已经保存，不代表问题已经自动修复或会在固定时间内回复。启用状态的管理员可以查看正文和图片，并可永久删除反馈。需要紧急支持时，请同时按组织规定的支持流程联系管理员。
