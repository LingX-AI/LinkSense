# 连接与管理 MCP

MCP 服务器为任务提供外部工具。你配置的个人 MCP 会自动装配到你的新任务。

## 添加 HTTP MCP

1. 进入“设置 → MCP”并选择“添加服务器”。
2. 选择 HTTP，填写名称和 Streamable HTTP 地址。
3. 选择无认证、Bearer Token 或 API Key。
4. 配置启动与工具超时。默认启动超时为 60 秒，默认工具超时为 600 秒。
5. 选择“测试连接”，确认能发现工具后保存。

优先使用 HTTPS。若使用 HTTP，凭据、参数和结果可能被中途读取或篡改，页面会要求单独确认风险。

## 添加 STDIO MCP

选择 STDIO 并填写单服务器 JSON，包含 `command`、可选 `args` 和 `env`。环境变量会加密保存且不回显。页面也支持粘贴只包含一个服务器的 `mcpServers` 结构。

任务容器不使用 npm 或 npx；常见的 `npx -y` 配置会转换为受控的 pnpm 执行方式。

## 超时设置

启动超时控制 MCP 初始化等待时间，工具超时控制单次工具调用等待时间。个人 MCP 会按可选服务器装配；连接失败时该服务器工具不可用，不提供“必须连接”开关。

## 更新与删除

- 启用或停用影响后续新任务。
- 编辑 HTTP 凭据或 STDIO `env` 时，留空可保留已保存秘密；填写空对象会清空 STDIO 环境变量。
- 删除会永久移除服务器配置、加密凭据和环境变量。

:::warning 信任边界
只连接可信 MCP。MCP 工具可能接收任务参数、访问外部系统并返回内容；使用前检查服务器来源、权限范围和网络地址。
:::
