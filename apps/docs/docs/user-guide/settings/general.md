# 常规设置

进入账户菜单，选择“设置 → 常规”。

## 界面语言

LinkSense 支持简体中文和 English。选择语言后会立即切换界面，并把偏好保存到账号，在 Web 与 Teams 中保持一致。

帮助中心有独立语言菜单。通过 LinkSense 问号按钮进入帮助中心时，会自动使用当前界面语言。

## 执行中发送新消息

选择任务仍在运行时新消息的默认处理方式：

- 引导当前执行：把纯文本补充要求加入正在运行的轮次。
- 排队为下一条请求：等当前轮次结束后再启动。

包含附件或明确选择插件、Skill、知识库的请求会自动排队，即使默认偏好是引导当前执行。

设置保存失败时，页面会恢复到之前的值并显示错误。确认网络恢复后重试。

## 浏览器通知

浏览器通知默认关闭。打开“启用浏览器通知”开关时，如果尚未授权，浏览器会询问是否允许 LinkSense 发送系统通知；只有选择允许后才会启用。成功开启后，LinkSense 会立即发送一条测试通知；也可以随时点击“发送测试通知”再次检查。

如果当前浏览器尚未有效开启通知，而且浏览器支持通知、权限也没有被永久阻止，LinkSense 会在界面左下角显示通知引导卡。点击“开启”会执行与设置页相同的完整启用和测试流程；点击“暂时不用”只会在本次浏览器会话内隐藏提示，下次重新打开浏览器后仍可再次看到。权限已被浏览器阻止时不会显示无法使用的引导卡，请先在网站权限中允许通知。

这个开关只对当前登录用户和当前浏览器生效，不会同步到其他浏览器或设备。LinkSense 页面需要保持打开，页面处于后台时仍可通知，但关闭页面或浏览器后不会通知。LinkSense 不使用 Web Push 或 Service Worker 在后台推送。

启用后，普通任务或自动化进入终态时会触发通知，状态按照实际结果显示：

- 成功：任务成功完成；自动化还必须已经产生可查看的结果。
- 失败：任务执行失败，或自动化结束但没有产生可查看的结果。
- 已中断：任务或自动化被中断。

首次启用时只从当前时刻开始监听，不会补发此前已经结束的历史任务通知。

无论你是否正在查看刚刚结束的任务页，LinkSense 都会发送系统通知。通知标题显示任务名称；正文显示它是普通任务还是自动化，以及“成功”“失败”或“已中断”的实际状态。任务名称会出现在浏览器和操作系统通知界面中，但通知不会包含输入内容、回答、错误详情、附件或产物名称。点击通知会聚焦 LinkSense 并直接打开对应任务。

如果浏览器不支持通知、无法保存设置、无法连接任务完成通知服务，或通知权限已被拒绝，设置页会显示对应说明；权限、测试通知和完成监听基线全部就绪后，开关才会真正保存为开启。浏览器把既有授权重置为“询问”时，可点击“重新授权并发送测试通知”；权限被拒绝后，需要先在浏览器的网站权限中允许 LinkSense 通知，再重新打开开关。如果页面提示测试通知已发送但系统没有显示，请继续检查操作系统是否允许当前浏览器发送通知，以及是否开启了免打扰或专注模式。

## 安装到桌面或主屏幕

LinkSense 提供 Web 应用安装信息。浏览器支持时，可以从浏览器菜单选择“安装应用”“添加到主屏幕”或同类入口，以独立窗口打开 LinkSense。具体入口名称由浏览器和操作系统决定。

安装不会启用离线模式，LinkSense 仍需连接部署服务。安装后从主屏幕启动会回到应用入口，并继续使用浏览器保存的登录会话；共享设备上使用完毕后仍应正常退出账号。
