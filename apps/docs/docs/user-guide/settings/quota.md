# 额度与使用分析

进入“设置 → 额度”，查看自己的剩余额度和使用分析。开放注册用户和组织成员使用相同的页面。

## 概览

查看本周已用、剩余额度、每周限额和下次重置时间。不限额账号仍显示实际使用量。周额度按系统时区每周一重置；管理员手动重置后，概览显示重置后的使用量，分析中的历史消费不会清空。

数值单位在中英文界面均为 credits，四舍五入显示为整数，实际扣费仍保留小数精度。小于 0.5 credits 的消费可能显示为 0，但仍计入统计。

## 分析

可查看最近 7 天或 30 天的数据，日期按浏览器所在时区展示。30 天仅为统计周期，不是月额度限制。

- 消费历史：按用途或模型查看每日消费和分类占比，使用消费发生时的扣费记录。
- 任务用量排行：展开查看模型与用途明细，或打开原任务；未关联任务和已删除任务的消费单独汇总。
- 插件与 MCP 调用：统计保留任务中已结束的调用，包含失败调用；调用次数不等于扣费次数。
- 技能使用：同一轮次内同一技能计一次。
- 消息：统计已进入任务轮次的用户消息，按模型分类，不含 AI 回复、待发送消息和分叉复制的历史消息。

图表最多展示五个分类，较多分类合并为“其他”。独立取整后，各分类显示值之和可能与总量略有差异。
