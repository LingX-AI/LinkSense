# 个人资料与个人用量

进入“设置 → 个人资料”管理账号的可见信息和个人使用统计。

## 修改显示名称

选择编辑名称，输入新名称并保存。名称会用于侧边栏、管理员用户列表和协作相关的安全展示，不会改变登录邮箱。

## 上传头像

选择头像区域上传受支持的图片。页面会校验文件类型和大小；保存后 Web 与 Teams 使用同一头像。删除或替换只影响显示，不会改变任务历史归属。

## 查看个人用量

个人资料页可显示：

- 累计 Token、任务和轮次数。
- 模型调用数、活跃天数与平均每轮 Token。
- 最近 365 天的 Token 活动热力图。
- 当前与最长连续使用天数。

这些数据用于个人了解使用情况，不是用量设置、账单或执行限制。历史任务删除后，最小活动和用量事实仍可能保留在统计中，但不会恢复任务正文。

## 无法更新

检查输入是否满足页面限制，然后重试。若账号已被停用，当前会话会失效，无法继续修改资料。
