# 外观与字号

进入“设置 → 外观”调整只属于你的界面显示偏好。

## 主题

可选择：

- 系统：跟随操作系统或宿主 WebView 的明暗偏好。
- 浅色：始终使用浅色界面。
- 深色：始终使用深色界面。

切换只改变视觉呈现，不影响任务内容、文件或执行状态。

## UI 字号

在页面提供的范围内调整基准字号。导航、表单、按钮、设置页和任务界面会同步变化，并保持原有信息层级。

文档、Markdown、Office 或 PDF 预览中的内容字号可能由对应查看器独立控制。

## 多端一致性

外观偏好保存到账号，在浏览器 Web 与 Teams 中保持一致。系统主题会根据当前设备分别解析，因此不同设备可能显示不同明暗模式。

如果大字号造成某个第三方文档预览过于拥挤，可使用预览自身的缩放控件，不必降低整个 LinkSense 界面字号。
