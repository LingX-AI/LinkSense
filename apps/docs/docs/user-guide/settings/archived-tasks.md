# 已归档任务

进入“设置 → 已归档任务”查看从最近任务列表移出的内容。

## 恢复任务

选择“取消归档”后，任务会回到左侧最近任务列表，并按最近更新时间参与排序。恢复不会重新运行任何历史轮次。

## 删除单个任务

永久删除前会要求确认。删除后不能恢复任务正文、附件、消息和可访问成果。

## 清空全部归档任务

“清除全部已归档任务”只影响当前账号的归档任务，不会删除未归档任务。该操作不可撤销，应先下载仍需保留的成果。

## 保留范围

任务被硬删除后，为审计、安全、资源清理和用量统计保存的最小事实可能继续存在，例如任务或轮次计数、Token 与费用快照。它们不包含可用于恢复的任务标题、正文、文件内容或工具参数。
