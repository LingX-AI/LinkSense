# 文件、预览与成果

## 添加附件

在任务输入区选择附件并等待上传完成，再发送请求。常见办公文档、PDF、文本、图片、表格、演示文稿和压缩包可作为任务材料；实际大小和类型限制以页面提示及部署配置为准。

在提示中明确指出文件名和处理目标，尤其是一次上传多个文件时。

## 预览文件

受支持的附件和成果可以在任务内预览。不同格式会提供相应的分页、缩放、工作表或幻灯片操作。若格式不能安全预览，仍可在有权限时下载原文件。

预览只用于查看，不会改变原文件。HTML 成果会在隔离的安全区域中显示，不能访问 LinkSense 主页面权限。

演示文稿、Word、Excel 和 HTML 预览支持选择具体内容并添加修改要求。可以累积多条后一次发送，详见[在文件预览中添加批注](./file-annotations.md)。

## 下载成果

当 LinkSense 生成 Word、Excel、PPT、PDF、图片或其他文件时，文件会以成果卡片显示。选择下载后，系统签发短时有效的下载地址。

如果下载链接过期，从任务中再次选择下载即可；不要把临时下载地址当作永久共享链接。

## 集中查看任务产物

从侧边栏进入“知识库”，再选择“任务产物”标签页，可以按任务名称和生成时间查看当前账号任务中已登记的成果文件。选择支持的文件可沿用任务内预览器查看；任何列表文件都可以直接下载。已归档任务的产物仍会标注并保留在列表中。

搜索框会同时匹配任务名称和文件名。选择任务名称可以返回原任务查看生成背景；任务被永久删除后，不再通过该列表访问其产物。

## 让结果更可用

- 明确文件类型和命名要求。
- 需要多个文件时说明目录或压缩包结构。
- 先检查预览，再要求修改。
- 重要成果下载后保存到组织批准的存储位置。

:::warning 敏感信息
不要上传超出工作需要的密码、密钥、个人隐私或机密数据。插件和外部工具可能按其声明能力处理任务输入，请在使用前查看风险说明。
:::
