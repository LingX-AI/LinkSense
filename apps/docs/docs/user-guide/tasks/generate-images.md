# 生成图片

管理员配置并启用图片生成模型后，可以在普通任务中直接描述希望生成的图片。LinkSense 会选择内置图片生成能力，并把成功生成的图片登记为任务成果。

## 写出清晰要求

建议说明：

- 主体：人物、产品、场景或图形元素；
- 风格：摄影、插画、3D、海报、图标等；
- 构图：视角、布局、留白、颜色和光线；
- 文字：需要准确出现的短文案及位置；
- 输出：图片数量、尺寸或横竖比例、是否需要透明背景。

例如：“生成一张 1024×1024 的极简产品图标，主体完整位于画布内，四周留白，透明背景，只生成 1 张。”未指定数量时通常生成一张；实际数量和尺寸还受当前服务商与模型限制。

## 透明背景

需要贴纸、图标、商品抠图或可叠加素材时，明确写出“透明背景”。简单且边缘清楚的主体可以自动处理；头发、毛发、玻璃、烟雾、发光和半透明材质需要模型原生支持高质量透明边缘。如果当前模型不支持，LinkSense 会显示限制，不会悄悄换成质量较差的结果。

## 查看结果与费用

生成完成后，图片会出现在任务成果中，可以预览或下载；也可以在“资料库 → 任务产物”集中查找。管理员按图片生成服务配置每张价格，实际生成张数会计入用量与 credits。

## 失败时

- “尚未配置或未启用”：联系管理员完成图片生成模型设置。
- 服务商拒绝：检查提示词、模型或管理员配置，修改后再提交。
- 服务暂不可用：稍后再试。
- 透明背景不支持：改用支持原生透明的模型，或在边缘要求允许时选择普通背景。
- 页面提示结果登记或用量记录失败时，不要立即重复生成；服务商可能已经处理并计费，先联系管理员核对。

普通文件成果的预览、下载和临时链接规则见[文件、预览与成果](./files-and-results.md)。
