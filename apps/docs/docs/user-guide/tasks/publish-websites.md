# 发布和管理站点

LinkSense 可以把任务中已登记的 HTML 网页成果发布为公开站点。访问者不需要登录，任何获得链接的人都可以打开，因此发布前必须检查网页中是否包含敏感信息。

## 发布新站点

1. 在任务中打开一个 HTML 成果的预览。
2. 选择预览工具栏中的“发布为站点”。
3. 选择“新建站点”，填写站点名称和可选简介。
4. 按需填写链接名称；留空时由 LinkSense 自动生成。
5. 选择“发布站点”，等待页面显示站点链接。
6. 复制链接并在未登录窗口中检查内容和交互。

同一 HTML 再次点击“发布为站点”时，会显示它已关联站点的当前链接和发布状态；也可以选择“更新其他站点”。

自定义链接名称只能使用 3–80 位英文字母、数字或连字符，不能以连字符开头或结尾。如果名称已被占用，请换一个名称。

网页可以包含成果登记时一同保存的 CSS、JavaScript、图片、字体和其他静态资源。只有单个 HTML 文件但引用了已丢失的本地文件时，发布会失败；请让 LinkSense 重新生成并登记完整网页成果。

## 更新已有站点

从新的 HTML 成果发布时，可以选择“更新已有站点”，搜索并选择你拥有的站点。更新成功后：

- 站点沿用原链接、名称和简介；
- 当前发布内容切换到新的网页成果；
- 来源任务更新为提供新网页的任务；
- 原本处于“未发布”的站点仍保持未发布，需要在“我的站点”中重新发布。

也可以进入“资料库 → 我的站点”，从站点菜单选择“更新发布”，再选择当前来源任务中的网页成果。来源任务已经删除时，请从新的任务成果发起“更新已有站点”。

## 管理我的站点

进入“资料库 → 我的站点”，可以搜索站点名称或链接，并按“已发布”或“未发布”筛选。

每个站点提供以下操作：

- **访问或复制链接**：打开当前公开版本，或把链接发送给其他人。
- **编辑**：修改名称、简介或链接名称。修改链接名称后，旧链接立即失效。
- **更新发布**：从来源任务的 HTML 成果中选择一个新版本。
- **取消发布／重新发布**：控制访客是否能访问；取消发布会保留站点、链接占用和已保存版本。
- **下载网页包**：下载当前版本的完整 ZIP，便于留档或迁移。
- **删除站点**：永久删除站点、全部发布版本和链接占用。原任务与原始成果仍会保留，删除后的链接名称可以被重新使用。

永久删除来源任务时，关联站点会自动变为“未发布”，但已保存的站点版本仍可在“我的站点”中下载。以后可以从其他任务生成新网页，选择“更新已有站点”重新关联并发布。

## 公开访问与安全边界

公开站点运行在隔离区域中，不能读取 LinkSense 的登录 Cookie、本地存储或父页面，也不能注册 Service Worker。它适合静态网页和浏览器内交互，不会运行服务端程序，也不会继承你的 LinkSense 权限。

外部 HTTPS 资源由访问者的浏览器直接加载，仍受资源可用性和跨域规则影响。站点不能依赖 LinkSense 登录态、服务器路由回退或浏览器持久化同源存储。发布前请确认：

- 页面及其静态资源能够完整加载；
- 没有密码、Token、个人隐私、内部地址或不应公开的任务内容；
- 表单和外部请求不会把数据发送到不可信服务；
- 取消发布、修改链接或删除站点后，旧链接的行为符合预期。

任务成果的预览、下载和集中管理见[文件、预览与成果](./files-and-results.md)。
