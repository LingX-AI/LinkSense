# 使用语音输入

语音输入只负责把你说的话转换为输入框文字，不会自动提交任务，也不会把录音作为任务附件。

## 录制并转写

1. 在任务输入框或 Office 选区操作输入框中选择麦克风按钮。
2. 首次使用时，允许当前 LinkSense 页面访问麦克风。
3. 看到录音时长和波形后开始说话。
4. 选择停止按钮；录音达到 5 分钟时也会自动停止。
5. 等待“正在转写语音”结束。
6. 检查并编辑写入输入框的文字，再自行选择发送或执行操作。

转写期间不能重复开始录音或提交当前输入。已输入的文字会保留，转写内容会写入当前草稿。

## 录音限制

- 录音必须至少持续 1 秒。
- 单次录音最长 5 分钟。
- 音频超过安全传输大小时，需要缩短后重新录制。
- 浏览器必须支持 `MediaRecorder`，并且设备存在可用麦克风。

Web 与 Teams 使用相同规则。系统只在当前录音和转写请求期间临时处理音频；原始录音不会作为附件保存到任务、文件存储、工作区、审计或日志。

## 无法使用时

- 权限被拒绝：在浏览器或 Teams 的站点权限中允许麦克风，再重试。
- 找不到设备：检查麦克风连接和系统输入设备。
- 设备被占用：关闭正在独占麦克风的应用后重试。
- 未识别到内容：靠近麦克风、减少背景噪声并重新录制。
- 转写超时或失败：稍后重试，或继续使用键盘输入。

:::warning 隐私提示
录音会被发送到部署方配置的语音识别服务完成转写。不要朗读密码、密钥或超出工作需要的敏感信息。
:::
