# 创建任务分支与调整顺序

## 从回复创建分支

在一个已经停止的任务中，找到要保留为分叉点的助手最终回复，选择消息操作中的“分支到新聊天”。LinkSense 会创建并打开一个新任务，复制截至该回复的对话、附件、成果、知识库引用以及可继续使用的运行上下文。

分支不会复制分叉点之后的内容，也不会修改原任务。新任务使用带序号的标题，初始为未置顶状态；此后两个任务的消息、文件和运行相互独立。

以下状态不能创建分支：

- 原任务仍在运行、正在启动或存在排队请求。
- 选中的回复不是某个已结束轮次的最终助手回复。
- 原任务已归档，或运行上下文暂时无法安全复制。

创建失败不会产生一个可见的半成品任务；确认原任务已经停止后再重试。

## 调整任务顺序

可以在侧边栏分别拖动“置顶”和“最近”分组中的任务。任务只能在当前分组内排序；先置顶或取消置顶，再调整其所在分组的顺序。

使用键盘时，聚焦任务排序控件，按空格选中，使用上下方向键移动，再按空格保存；按 Escape 取消。若其他窗口同时改变了任务列表，保存可能被拒绝，刷新后重新排序即可。

## 与归档和删除的关系

分支和原任务都是独立任务。归档或永久删除其中一个不会自动处理另一个。若分支保留了复制成果，请仍以各自任务中的下载入口和权限为准。
