# 使用项目整理任务

项目把相关任务和文件放在一起。同一项目中的任务共用项目文件；没有加入项目的个人任务共用一个公共工作区。插件、Skills、工具和个人登录状态在你的个人任务之间共用。

## 创建和使用项目

1. 点击侧边栏“项目”旁的 **+**，输入名称并创建。
2. 新建任务时，从输入框上方选择项目。
3. 发送消息开始工作。项目中的其他任务可以继续使用这里的文件。

每个任务最多属于一个项目。你可以展开或收起项目，拖动项目调整顺序，也可以置顶任务。项目名称和任务归属会保存到账号，展开状态保存在当前浏览器。

## 移动任务

拖动任务到目标项目，或使用任务菜单中的“移动到项目”。任务停止运行后才能移动；有排队消息、等待处理的计划或正在推进的目标时，需要先结束这些工作。

移动后，新消息使用目标项目的文件。原项目文件会留在原处，历史消息中的附件仍可打开。已经上传但尚未发送的附件也会保留。

从回复创建分支时，新任务继承所属项目，共用项目文件。两个任务仍有各自的消息记录。

## 删除任务或项目

删除任务会删除该任务的消息记录，保留项目文件。删除项目会把任务移回公共工作区，保留原项目文件和历史附件。需要清理文件时，请单独处理文件。

应用服务拥有自己的工作环境。把应用任务放进项目只用于整理任务，不会把应用服务的文件或登录状态放进个人工作区。

## 运行环境与历史文件

你的任务使用同一个个人运行环境。空闲一段时间后，系统会停止环境以节省资源，文件和个人设置仍然保留。下次使用时会自动启动；需要持续运行时，可以在设置中开启“保持运行”。

升级前的任务文件会保存在对应项目的 `imports/任务编号` 文件夹中，方便继续查看和使用；历史附件仍可从消息记录打开。
