# 查看任务进度、成果与来源

## 执行动态

运行中的任务会按时间显示可见的执行动态，例如思考进度、计划、工具操作、上下文压缩和状态变化。展开条目可以查看 LinkSense 允许展示的详情；涉及密钥、内部地址或受保护数据的内容会被隐藏。

网络重连、页面刷新或同一轮事件重新投递会继续同一轮次，不代表任务自动执行了第二次。历史较长时，页面会分批加载更早的问答；滚动或选择历史分组即可继续查看。

## 任务概览

任务顶部的概览入口集中显示：

- 子智能体及其当前状态和完成数量；
- 已登记的成果文件，可直接预览或下载支持的类型；
- 助手回复中识别出的外部网页来源。

没有使用子智能体、没有生成文件或没有外部来源时，对应区域会显示为空。执行计划和工具细节以消息下方的执行动态为准。

## 外部来源与知识库引用

“来源”列表会整理助手回复中的外部网页链接并去重。选择来源会在新窗口打开原网页；网页标题不可用时会显示网址。来源列表只帮助你回到原页面，不代表 LinkSense 对外部内容作额外背书。

知识库引用使用回复中的编号标记，并可打开引用片段或原文位置，和外部网页来源是两套不同入口。详见[使用知识库与查看引用](../knowledge-bases/use-and-citations.md)。

## 核对重要结果

- 检查结论是否与来源和附件一致。
- 对会影响财务、法律、医疗、安全或生产系统的决定，打开原始来源复核。
- 下载重要成果并保存到组织批准的位置；临时下载地址不能作为永久分享链接。

成果预览与下载见[文件、预览与成果](./files-and-results.md)。
