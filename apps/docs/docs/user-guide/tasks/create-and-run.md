# 创建与运行任务

## 写出可执行的要求

一条有效请求通常包含：

- 目标：最终要解决什么问题。
- 输入：需要阅读的文件、数据或知识库。
- 约束：语言、格式、篇幅、时间范围或必须遵循的规则。
- 交付物：只需回答，还是需要 Word、Excel、PPT、PDF、图片或压缩包。

## 选择模型与推理强度

点击输入框底部的模型与推理强度按钮，打开选择卡片。左右拖动滑条可预览不同强度，松手后保存；也可以点击滑条上的位置，或用键盘方向键调整。滑条只显示当前模型支持的档位。

点击卡片顶部的模型名称可切换模型，右上角的重置按钮可恢复当前模型的默认推理强度。切换模型时会保留可用的强度；如果新模型不支持该强度，则使用新模型的默认值。

模型选择器只显示管理员设为“对话可选”的对话模型。模型和推理强度在每个新轮次开始时确定；管理员后续修改配置不会重写已经运行或历史轮次。

如果原模型不再“对话可选”，页面会要求重新选择或使用对话默认模型。

## 添加能力

在发送前可以：

- 选择已安装且启用的插件或 Skill。
- 选择你有权使用的知识库。
- 查看个人 MCP 的连接状态。

所选资源只对本轮固化。能力被停用、凭据缺失或知识库权限失效时，启动前检查会阻止执行并给出可处理的提示。

如果更适合口述，可以使用[语音输入](./voice-input.md)把麦克风语音转成可编辑草稿；确认文字后仍需由你主动发送。

## 使用目标模式完成长任务

如果一条请求不是一次回复就能完成，可以使用[目标任务](./goal-tasks.md)。选择“+”，再选择“目标”，写清可衡量的结果，然后像普通任务一样添加附件、插件、Skill 或知识库。

目标任务会在用户消息下方显示目标标记，并在执行期间显示目标卡片。完成后，最终回复下方会显示达成目标的用时。

## 先规划再实施

需要先确认范围、风险和实施步骤时，选择“添加 → 计划模式”。LinkSense 会先分析需求、按需提出澄清问题，并在方案完成后等待你选择实施、修改、跳过或退出。具体行为见[使用计划模式](./plan-mode.md)。

输入 `/` 可以快速打开新任务、压缩上下文、插件、Skill、应用、知识库和 MCP 等功能入口；最终是否可用仍取决于当前任务状态和你的资源权限。

## 运行控制

- “停止”会请求中断当前运行。
- 网络短暂断开后，页面会尝试恢复同一轮次，而不是创建重复轮次。
- 页面刷新后可重新进入最近任务查看当前状态。
- 执行中的计划步骤、文件变化、成果和子智能体会汇总在任务概览中，选择相应条目可查看允许展示的详情。
- 任务失败时，先阅读页面错误提示；调整输入或缺失配置后再重新发送。

:::info 任务与轮次
一个任务可以包含多轮请求。继续对话会创建新轮次，但刷新、重连和同一轮的事件重投不会产生额外轮次。
:::
