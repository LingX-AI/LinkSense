# 管理任务历史

## 最近任务

左侧“任务”区域按最近更新时间显示未归档任务。滚动到底部时会继续加载。任务在后台完成且尚未查看时会显示未读状态，打开任务后即标记为已查看。

## 搜索任务

选择侧边栏“搜索”，可以匹配任务标题、消息、附件、成果、插件或 Skill。搜索结果只包含你有权访问的任务。

打开历史较长的任务时，LinkSense 会先显示最近内容，再分批加载更早的问答。需要引用或分享早期内容时，先把相应历史加载出来。

## 重命名与置顶

在任务操作中可以修改标题。置顶会让常用任务保持在列表前部；取消置顶后进入最近任务分组。置顶数量达到上限时，先取消一个旧任务。

置顶和最近任务均可在各自分组内拖动排序，也支持键盘操作；两个窗口同时更新顺序时，以服务端保存的最新版本为准。完整操作见[创建任务分支与调整顺序](./branch-and-organize.md)。

## 从历史回复继续不同方向

对已结束轮次的最终助手回复选择“分支到新聊天”，可以复制截至该回复的历史和运行上下文，形成一个不影响原任务的新任务。正在运行、存在排队请求或已归档的任务不能创建分支。

## 归档

归档会把任务移出最近任务列表，但不会立即删除内容。进入“设置 → 已归档任务”可以查看、恢复或删除归档任务。

## 永久删除

删除或清空归档任务是不可撤销操作。任务正文、附件和可恢复记录会按系统规则清理；为安全、审计和资源统计保留的最小活动、用量或成果元数据可能继续存在，但不能用来恢复任务内容。

:::tip 整理建议
置顶持续进行的工作，完成后归档；只有确认不再需要正文、附件和历史结果时才永久删除。
:::

## 分享当前对话

点击任务右上角“分享”，先查看弹窗中的预览，再选择“复制链接”。链接只包含这次预览中的消息和附件信息，不显示你的姓名；附件信息不提供公开下载。

预览在打开弹窗时固定，后续新增消息、继续生成的回答或对原内容的修改都不会加入本次分享。如果要分享更新后的内容，关闭弹窗后重新打开并复制新链接。新链接对应新的快照，旧链接保持不变。

分享预览不会自动加载尚未加载的历史消息。如需包含更早的对话，请先在原任务中加载相应历史，再打开分享弹窗。永久删除原任务后，其分享链接也会失效。
