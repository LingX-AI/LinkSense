# 按分类整理任务

任务分类可以帮助你按工作、项目或生活场景整理任务。分类仅对你自己可见，每个任务最多属于一个分类，也可以保留为未分类。

## 创建和使用分类

1. 点击侧边栏“任务”标题右侧的 **+**。
2. 输入分类名称，点击“创建”。名称最多 80 个字符，同名分类不能重复创建。
3. 新建任务时，点击输入框上方独立分类栏中的文件夹入口，选择所属分类。
4. 输入任务内容并发送。任务会显示在对应分类下。

点击侧边栏的分类名称可以展开或收起任务。分类和任务归属会自动保存，刷新或换设备后仍然可用。

每个分类的展开或收起状态会按当前账号保存在当前浏览器中，刷新后仍会保持；它不会同步到其他浏览器或设备。浏览器存储不可用时，分类默认展开。

上下拖动分类名称可以调整分类顺序，分类中的任务会随分类一起移动，任务归属保持不变。顺序会自动保存，刷新后仍然保留；新建分类显示在列表末尾。保存失败时会恢复原顺序。

从任务中的助手回复选择“分支到新聊天”时，新任务会继承原任务的分类；原任务未分类时，新任务也保持未分类。分支创建后，可以分别调整两个任务的分类。

## 调整已有任务的分类

拖动侧边栏中的任务名称，将它放到目标分类名称上；分类高亮后松开，即可完成归类。空分类和已收起的分类也可以接收任务。在同一组任务内上下拖动，仍然可以调整顺序。按 Escape 键或在目标区域外松开可取消拖动；保存失败时，任务会保留在原来的位置。

使用键盘时，聚焦任务的调整按钮，按空格键选中任务，再用上下方向键选择位置或分类，按空格键保存。

将指针移到侧边栏任务上，点击“移动到分类”图标，选择目标分类并保存。选择“未分类”可以移除原有分类归属。

如果新任务已经上传附件但尚未发送消息，也可以继续在输入框上方调整分类，输入内容和附件会保留。

置顶任务显示在“置顶”区域，同时保留所属分类。取消置顶后，任务会回到原来的分类中。

## 重命名或删除分类

点击分类右侧的更多操作按钮，可以重命名或删除分类。

删除分类会将其中的任务移回未分类，包括已归档的任务。任务内容会保留，置顶任务的置顶状态也会保留。
