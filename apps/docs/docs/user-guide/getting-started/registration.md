# 注册与激活账号

只有管理员开启“开放注册”并且认证邮件服务可用时，登录页才会显示“注册账号”。管理员直接创建的账号不需要走本流程。

## 申请激活邮件

1. 在登录页选择“注册账号”。
2. 输入可接收邮件的邮箱地址。
3. 选择“发送激活邮件”。
4. 前往邮箱打开一次性激活链接。

为避免泄露邮箱是否已经注册，提交页通常只显示统一结果。没有收到邮件时，请检查垃圾邮件并稍后重试；仍无结果时联系管理员确认开放注册和邮件服务状态。

## 设置密码并激活

在链接有效期内打开激活页，输入并确认新密码。密码必须为 8～16 个字符，并同时包含大写字母、小写字母、数字以及标点或符号。激活成功后系统会直接建立登录会话。

激活链接只能使用一次。链接过期、已经使用，或管理员关闭开放注册后，需要从注册页重新申请；关闭开放注册也会使尚未使用的激活链接停止生效。

## 注册账号的用量

管理员会为开放注册账号设置总 Token 额度。额度用尽后不能开始新任务、补充请求或使用语音转写，但正在运行的任务不受影响。可在个人资料和侧边栏查看剩余量，必要时联系管理员调整。

## 邮箱已经注册

如果页面明确提示邮箱已有账号，请返回登录页直接登录，或使用“忘记密码或首次设置密码”。不要反复申请激活邮件。
