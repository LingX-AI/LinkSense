# 密码、重置与单点登录

本页说明账号登录凭据的常见操作。LinkSense 不会在页面、日志或邮件中显示你的现有密码。

## 首次设置或重置密码

1. 在登录页选择“忘记密码或首次设置密码”。
2. 输入账号邮箱并提交。
3. 如果账号允许本地密码登录，系统会发送一次性安全链接。
4. 打开链接并设置符合页面要求的新密码。
5. 返回登录页使用新密码登录。

为避免泄露账号是否存在，提交后页面会使用统一提示。重置链接只能使用一次，并且有有效期；过期后重新申请。

## 在设置中修改密码

已登录用户可进入“设置 → 安全”，输入当前密码和新密码。修改成功后，现有登录会话会被撤销，需要重新登录。

## 单点登录账号

是否允许单点登录、本地密码或 Teams 登录由管理员配置。单点登录通过不代表账号一定已启用；首次创建或被停用的账号仍可能需要管理员处理。

:::warning 保护账号
不要把密码、重置链接、浏览器存储中的令牌或单点登录回调地址发送给任何人。
:::
