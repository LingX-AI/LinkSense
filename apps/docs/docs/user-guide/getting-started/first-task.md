# 创建第一个任务

任务是 LinkSense 中保存上下文、消息、文件和成果的工作空间。

## 首次准备

登录页和首次初始化页的右上角可以选择界面语言；登录后可以进入“设置 → 通用”调整。支持简体中文、英语、西班牙语、巴西葡萄牙语、法语和日语。

管理员首次使用、尚未配置模型时，“新任务”页面会显示“开始使用”引导，左侧账号菜单也会提供引导入口。账号与模型已就绪后，引导和菜单入口都会自动隐藏；普通成员不显示这些引导。

- 管理员可以选择“配置模型”，进入[模型设置](../../admin-guide/model-settings.md)，添加模型、测试连接并保存。
- 如果模型状态加载失败，选择“重试”。模型配置尚未就绪或状态尚未成功加载时，不能发送新任务。

普通成员如尚无可用模型，需要联系管理员配置，完成后刷新“新任务”页面。

可以关闭引导，当前浏览器会按账号记住关闭状态。管理员尚未完成模型配置时，可从左侧账号菜单选择“开始使用引导”再次查看。

## 提交任务

1. 从左侧选择“新任务”。
2. 在输入框中写清目标、可用材料和期望输出。
3. 如有需要，添加文件、插件、Skill 或知识库。
4. 检查模型与推理强度。
5. 选择发送。

示例：

> 阅读附件中的销售数据，找出三个最重要的变化，生成一份中文摘要和 Excel 明细。

## 查看执行过程

提交后，任务会显示回答、工具或能力使用摘要以及已生成文件。任务标题会根据首次内容自动生成，你也可以在最近任务列表中重命名。

如果任务仍在执行，可以停止当前执行，也可以按个人偏好把新文本作为“引导当前执行”发送，或排队为下一条请求。包含附件或指定能力的新请求会自动排队。

## 继续完善结果

无需为同一工作重新创建任务。直接在当前任务中补充修改要求，例如：

- 把摘要改为管理层能快速阅读的格式。
- 在表格中增加同比列。
- 将最终结论导出为 PDF。

每一轮都会保留在任务历史中，生成的文件会显示为可下载成果。
