# 连接和使用Microsoft Teams

## 连接步骤

1. 在 Microsoft Entra 中注册单租户应用并创建客户端密钥；创建使用相同应用 ID 和租户的 Azure Bot，启用 Microsoft Teams 渠道。
2. 在 LinkSense 的“设置 → 消息渠道”中选择“连接 Microsoft Teams”，填写应用 Client ID、密钥、租户 ID，以及允许使用的用户在 Microsoft Entra 中的对象 ID。
3. 保存后打开“查看配置”，将“消息接收地址”填入 Azure Bot 的消息传送终结点。此地址必须能从公网通过 HTTPS 访问。
4. 使用 Teams Developer Portal 创建含该机器人的 Teams 应用，按需启用个人、群聊和团队使用范围，将应用发布或上传到自己的租户并安装。
5. 使用指定用户私聊机器人，或在群聊/频道中 @ 机器人发送文本。首次合法消息到达后，“等待消息验证”会变为“在线”。

## 支持范围

- 仅允许配置的一个成员发送文本私聊或群内 @ 消息。如果只需私聊，可以取消允许群内消息。
- 每个聊天继续自己的 LinkSense 任务；Teams 频道中的不同帖子分别对应任务。
- 群内回复对同群成员可见。完整执行过程、文件与超长结果请到 LinkSense 查看。
- 暂不处理图片、文件、语音和卡片。

## 无法收到消息或回复

检查应用凭据、成员 ID、应用权限和网络。确保发消息的是配置的成员，群内消息需要 @ 机器人。应用还可能需要组织管理员批准。

仅本机可访问的地址不能接收 Teams 消息。先配置 LinkSense 的公网 HTTPS 地址，再复制消息接收地址，并确认 Azure Bot 与 Teams 应用使用相同的应用 ID。本接入支持公共云单租户机器人。

## 断开或更换密钥

选择“断开”并确认后，待处理的渠道消息和待发送回复会移除；已创建的 LinkSense 任务和平台上的应用会保留。需要更换应用或密钥时，请断开后重新配置。
