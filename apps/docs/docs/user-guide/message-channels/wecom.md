# 连接和使用企业微信

## 连接步骤

1. 在企业微信创建企业内部智能机器人，选择 API 模式和长连接。记录机器人 ID 与密钥，并将机器人开放给需要使用的成员。
2. 在 LinkSense 的“设置 → 消息渠道”中选择“连接企业微信”，填写机器人 ID、密钥及允许使用的成员账号（企业微信通讯录 userid）。
3. 保存后等待显示“在线”。在企业微信私聊机器人发送文本，或把机器人加入群后由该成员 @ 它发送文本。

## 支持范围

- 仅允许配置的一个成员发送文本私聊或群内 @ 消息。如果只需私聊，可以取消允许群内消息。
- 每个私聊或群聊会继续各自对应的 LinkSense 任务。
- 群内回复对同群成员可见。完整执行过程、文件与超长结果请到 LinkSense 查看。
- 暂不处理图片、文件、语音和卡片；企业微信客户消息不属于本次接入范围。

## 无法收到消息或回复

检查应用凭据、成员 ID、应用权限和网络。确保发消息的是配置的成员，群内消息需要 @ 机器人。应用还可能需要组织管理员批准。

无需公网消息接收地址。请保持 LinkSense 运行，并允许服务器向平台发起 HTTPS 和 WebSocket 连接。

## 断开或更换密钥

选择“断开”并确认后，待处理的渠道消息和待发送回复会移除；已创建的 LinkSense 任务和平台上的应用会保留。需要更换应用或密钥时，请断开后重新配置。
