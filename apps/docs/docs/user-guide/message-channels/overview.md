# 消息渠道概览

进入“设置 → 消息渠道”，可以把 LinkSense 连接到常用聊天平台。渠道消息仍会在你的私有任务空间中处理，并受模型、能力、并发和 credits 额度限制。

## 选择渠道

| 渠道 | 连接方式 | 支持的消息 | 网络要求 |
| --- | --- | --- | --- |
| [微信](./weixin.md) | 扫码连接个人微信 | 扫码账号本人的文本与可转写语音 | 无需公网回调 |
| [飞书](./feishu.md) | 扫码创建或更新官方机器人 | 创建者的一对一私聊文本 | 出站 HTTPS 与 WebSocket，无需公网回调 |
| [企业微信](./wecom.md) | 机器人 ID、密钥与允许成员 | 指定成员的私聊文本和群内 @ 文本 | 出站 HTTPS 与长连接，无需公网回调 |
| [钉钉](./dingtalk.md) | Client ID、Client Secret 与允许成员 | 指定成员的私聊文本和群内 @ 文本 | Stream 长连接，无需公网回调 |
| [Microsoft Teams](./teams.md) | Entra/Azure Bot 应用与允许成员 | 指定成员的私聊、群聊或频道 @ 文本 | 必须提供公网可访问的 HTTPS 消息接收地址 |

各渠道会在同一聊天中继续对应的 LinkSense 任务。群聊回复可能被同一群中的成员看到；发送前不要包含不应在群内公开的内容。

## 在哪里查看完整结果

消息渠道主要返回最终文本。工具调用、执行过程、附件、生成文件和过长结果请回到 LinkSense 对应任务查看。渠道暂不支持的文件或消息类型，也可以直接在 Web 端添加到任务。

## 连接前检查

- 使用你自己的平台账号或组织批准的机器人应用。
- 确认允许发送消息的成员身份填写正确。
- 企业代理、防火墙和 DNS 不应阻断渠道所需的出站连接。
- 只有 Teams 需要公网 HTTPS 回调；不要把密钥、二维码、配对码或回调密钥发送给他人排查。
