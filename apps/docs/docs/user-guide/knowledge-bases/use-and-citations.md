# 在任务中使用知识库与引用

## 选择知识库

在任务发送前选择“添加知识库”，搜索并勾选一个或多个可用知识库。选择只对本轮固化，后续轮次可以调整。

如果知识库被停用、归档、删除或你的访问被撤销，启动前检查会提示不可用。LinkSense 不会静默扩大检索范围。

## 提问方式

建议明确要求使用所选知识库并处理资料不足，例如：

> 只根据本轮选择的知识库回答，列出依据和来源；如果资料不足，请明确说明。

## 阅读引用

回答使用知识库内容时会显示编号引用。打开引用可以看到：

- 知识库与文档名称。
- 回答生成时使用的精确文档版本。
- 标题路径和命中内容。
- 经验证的页码；没有可靠页码时只显示文档级来源。

可以在解析内容与同版本原文之间切换，并独立下载原件。

## 历史引用

引用固定到回答当时的版本。之后替换文档不会把历史回答指向新内容。如果来源被永久删除，引用会保留历史名称与位置摘要，但正文、原文预览和下载不可用。

## 对话中的图片

知识库读取时合法提供给任务的新图片会独立保存为对话附件。后续轮次不需要重新选择知识库，就能继续查看这些图片。知识库重建、删除或撤销共享，不会删除已经保存在对话中的图片副本；打开原文引用仍需具备来源访问权限。

图片只对有权访问该任务的用户开放，并遵循任务产物的保留规则。此行为只适用于启用图片副本保存后的新读取；不会为历史回复自动补建图片或修复已有破图。

:::info 检索不可用
知识库检索服务暂不可用时，你仍可以继续使用插件、Skill 和普通附件。稍后重试知识库任务，或请管理员在系统健康页检查检索链路。
:::
