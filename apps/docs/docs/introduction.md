# LinkSense 帮助中心

这里集中说明如何使用 LinkSense 完成任务、管理自动化、使用插件与知识库，以及如何执行管理员配置与治理工作。

## 选择你的指南

- [用户指南](./user-guide/overview.md)：适合所有使用 LinkSense 创建任务、上传文件、安装插件或管理个人设置的用户。
- [管理员指南](./admin-guide/overview.md)：说明用户、权限、插件、知识库、模型、认证、健康、审计和用量管理。

所有帮助文档都可以公开阅读。管理员指南中的页面和操作仍受 LinkSense 本身的管理员权限保护。

## 如何使用帮助中心

1. 在左侧目录按功能查找文档。
2. 使用顶部搜索框搜索页面标题或正文关键词。
3. 使用右上角语言菜单切换简体中文或 English。
4. 从 LinkSense 侧边栏的问号按钮进入时，系统会优先打开与当前页面相关的说明。

:::tip 搜索提示
搜索索引完全随帮助中心静态文件部署，不会把查询或文档内容发送给第三方搜索服务。
:::

## 文档范围

文档描述 LinkSense 当前界面中可见的产品能力。部署参数、数据库维护和基础设施密钥不属于普通界面操作；管理员文档会说明哪些设置只能由部署人员管理。
