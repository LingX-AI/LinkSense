# Install Skills from ClawHub

ClawHub is an external source of Skills. LinkSense displays metadata synchronized locally, but neither LinkSense nor ClawHub review or endorse every third-party Skill shown there.

## Find and inspect a Skill

Go to **Plugin Center → ClawHub Skill repository**, search by name, and optionally sort by downloads or stars. Open the details to inspect the author, version, update time, topics, platform requirements, changelog, and canonical ClawHub page.

Download and star counts can provide context about usage, but they are not a security review.

## Install or update

1. Choose the version to install.
2. Wait for LinkSense to fetch and validate the package.
3. Review source, integrity, and risk notices.
4. Confirm installation into your personal Skills.

When you already have the same source installed, LinkSense offers an update; it does not reinstall the same version. The installed Skill remains visible and manageable under **My capabilities**.

## Security and availability

LinkSense may block installation when a Skill is flagged, has no installable version, does not meet platform requirements, or fails integrity validation. Do not bypass the warning or treat credentials requested by an unknown Skill as ordinary settings.

Refresh later when the repository is temporarily unavailable or has not synchronized any data. Uninstalling removes your personal copy and its configuration; it does not change repository metadata or delete completed task history.
