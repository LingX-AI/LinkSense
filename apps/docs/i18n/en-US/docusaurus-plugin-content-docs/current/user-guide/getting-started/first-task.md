# Create your first task

A task is a workspace that keeps related messages, files, context, and deliverables together.

## Submit work

1. Select **New task** in the sidebar.
2. Describe the objective, available material, and expected output.
3. Add files, plugins, Skills, or knowledge bases when needed.
4. Check the model and reasoning effort.
5. Send the request.

Example:

> Review the attached sales data, identify the three most important changes, and create an English summary plus an Excel detail sheet.

## Follow execution

The task displays responses, capability activity, and generated files. LinkSense generates a title from the first request; you can rename it from the recent-task list.

While work is running, you may stop it, steer it with a text-only clarification, or queue another request. Requests with attachments or explicit capability selections are queued automatically.

## Refine the result

Continue in the same task instead of starting over:

- Rewrite the summary for an executive audience.
- Add a year-over-year column to the workbook.
- Export the final conclusion as PDF.

Each turn remains in the task history, and generated files appear as downloadable deliverables.
