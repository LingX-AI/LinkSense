# Register and activate an account

The sign-in page shows **Create account** only when an administrator has enabled open registration and the authentication email service is available. Accounts created directly by an administrator do not use this flow.

## Request an activation email

1. Select **Create account** on the sign-in page.
2. Enter an email address that you can access.
3. Select **Send activation email**.
4. Open the one-time activation link from your inbox.

To avoid disclosing whether an address is registered, the request page normally shows the same result for every submission. Check spam and retry later if no email arrives. If it still does not arrive, ask an administrator to verify open registration and the email service.

## Set a password and activate

Open the link before it expires, then enter and confirm a new password. The password must contain 8–16 characters and include uppercase and lowercase letters, a number, and punctuation or a symbol. LinkSense signs you in after activation succeeds.

An activation link works only once. Request a new one if it expired, was already used, or open registration was disabled. Disabling open registration also invalidates activation links that have not yet been used.

## Usage available to registered accounts

Administrators assign a total token allowance to accounts created through open registration. When it is exhausted, you cannot start tasks, submit follow-ups, or transcribe voice input; a task that is already running is not interrupted. Check the remaining allowance in your profile or sidebar and contact an administrator if it needs to change.

## The email is already registered

If LinkSense explicitly says that the address already has an account, return to the sign-in page or use **Forgot password or set it for the first time**. Do not keep requesting activation emails.
