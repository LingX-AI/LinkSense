# Troubleshoot common problems

## Sign-in fails

- Use an enabled method and confirm the account is active.
- Request a reset for a local password.
- Restart SSO from the login page.
- Wait for login protection to cool down instead of retrying continuously.

## A task cannot start

Read the preflight message:

- Choose another model if the selected one is disabled.
- Remove or update an unavailable plugin or Skill.
- Fix a missing or conflicting explicit credential binding.
- Test the URL, authentication, and timeout of a required MCP server.
- Select a knowledge base that is still enabled and accessible.
- If your credit quota is exhausted, wait for the weekly or monthly reset when applicable. A total quota does not reset; ask an administrator to adjust it.

## Execution disconnects

Refresh and reopen the same task so LinkSense can recover the original turn. Do not submit repeated copies during a network interruption. Retry only after the turn has definitively failed.

If a plan decision cannot be submitted, check whether the task already entered a new turn, goal, or automation state; a stale decision cannot overwrite newer state. If branching fails, confirm that the source task has stopped, has no queued request, and is not archived.

## Upload or preview fails

- Check type, size, and batch limits.
- Ensure the extension matches actual file content.
- A preview failure does not necessarily mean the original is lost; try downloading.
- For knowledge documents, inspect the failed processing stage and retry.

## Search has no results

Help-center search is generated by a static production build and is not available in the development server. Product search returns only data your account can access.

## The Feishu bot does not respond

- Confirm that Feishu is connected under **Settings → Message channels**. Do not scan repeatedly while administrator approval is pending; the connection recovers automatically after approval.
- Only one-to-one private text from the bot creator is accepted. Group chats, other people, and non-text messages do not start tasks.
- A local deployment does not need a public callback, but the LinkSense environment must reach Feishu over HTTPS and WebSocket.
- If Feishu says the application does not exist, use the **Create a new application** path to replace the deleted application instead of scanning the old QR code.
- If an untitled task appears but never starts, refresh the task and channel status, then send one new short message instead of repeatedly submitting the original.

See [Connect and use Feishu](../message-channels/feishu.md) for connection, approval, disconnection, and recovery steps.

## Weixin does not respond

- Confirm that Weixin is **Online** under **Settings → Message channels**.
- The message must come from the account that scanned the code and be supported text or transcribable voice.
- If any QR, phone confirmation, or pairing-code step was not completed, reconnect and follow the current page.
- Check credit quotas, maintenance state, and task concurrency. Do not repeatedly send the same message.

See [Connect and use Weixin](../message-channels/weixin.md) for connection and disconnection steps.

## Contact an administrator

For system health, model, authentication email, knowledge processing, retrieval, or runner errors, provide the time, page, stable error message or code, and safe reproduction steps. Never send passwords, tokens, API keys, temporary URLs, or sensitive file contents.
