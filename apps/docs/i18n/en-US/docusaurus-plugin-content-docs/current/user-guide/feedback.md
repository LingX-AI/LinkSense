# Submit feedback

## Submit feedback

1. Select the **Feedback and help** question-mark button in the LinkSense sidebar.
2. Select **Feedback**.
3. Describe the page, steps, expected result, and actual result.
4. Add screenshots if useful, or paste images directly into the feedback field.
5. Review the content and select **Submit**.

Feedback text can contain up to 2,000 characters. The page shows the maximum number of images and per-image size. PNG, JPEG, WebP, and GIF are supported. Images that exceed format, size, or count limits are not submitted.

## What to include

Include the time, reproducible steps, visible error code, and impact when possible. Do not submit passwords, tokens, API keys, one-time links, QR codes, complete customer datasets, or unrelated sensitive screenshots.

## What happens next

A successful submission means the feedback was stored; it does not mean the issue was automatically fixed or that a response is guaranteed within a set time. Active administrators can read the text and images and can permanently delete the feedback. For urgent support, also use your organization's approved support channel.
