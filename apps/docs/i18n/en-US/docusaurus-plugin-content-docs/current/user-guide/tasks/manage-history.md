# Manage task history

## Recent tasks

The sidebar lists unarchived tasks by recent activity and loads more as you scroll. A task completed in the background shows an unread marker until you open it.

## Search

Use **Search** in the sidebar to find your own tasks. Results never include another user's task.

## Rename and pin

Rename a task from its actions. Pin ongoing work into the Pinned group; unpin it into Recent. If the pin limit is reached, unpin an older task first.

Pinned and recent tasks can each be reordered by drag and drop or keyboard. Concurrent changes from two windows use the latest server version. See [Branch and reorder tasks](./branch-and-organize.md) for complete instructions.

## Continue a different direction from history

Select **Branch into new chat** on the final assistant response of a finished turn to copy history and runtime context through that point into a new independent task. A task cannot be branched while running, when it has a queued request, or after it is archived.

## Archive

Archiving removes a task from the recent list without immediately deleting it. Open **Settings → Archived tasks** to restore or delete it.

## Permanent deletion

Deleting one task or clearing all archived tasks cannot be undone. Recoverable messages, attachments, and task history are removed according to system policy. Minimal audit, usage, or resource facts may remain, but cannot restore task content.

:::tip Organization
Pin active work, archive completed work, and permanently delete only after downloading anything you still need.
:::
