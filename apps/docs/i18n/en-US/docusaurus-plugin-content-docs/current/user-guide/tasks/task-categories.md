# Organize tasks with categories

Use categories to organize tasks by work, project, or personal activity. Categories are private to your account. Each task can belong to one category or remain unclassified.

## Create and use a category

1. Select **+** beside the **Tasks** heading in the sidebar.
2. Enter a category name and select **Create**. Names can contain up to 80 characters and must be unique within your account.
3. When starting a task, use the folder selector in the separate category bar above the input box to choose its category.
4. Enter your request and send it. The task appears under the selected category.

Select a category name in the sidebar to expand or collapse it. Categories and task assignments are saved across refreshes and devices.

Each category's open or collapsed state is stored for the current account in the current browser. It survives a refresh but does not sync to other browsers or devices. Categories default to open when browser storage is unavailable.

Drag a category name up or down to change its position. Its tasks move with it and keep their category assignments. The order is saved across refreshes, and newly created categories appear at the end. If saving fails, the previous order is restored.

When you select **Branch to new chat** on an assistant reply, the new task inherits the source task's category. If the source is unclassified, the new task is also unclassified. After branching, you can change each task's category independently.

## Move an existing task

Drag a task name onto a category name in the sidebar. Release it when the category is highlighted to move the task there. Empty and collapsed categories also accept tasks. Dragging within the same task group continues to change the order. Press Escape or release outside a valid target to cancel. If saving fails, the task stays in its original position.

With a keyboard, focus the task's reorder button and press Space to pick it up. Use Up and Down to select a position or category, then press Space to save.

Hover over a task in the sidebar, select **Move to category**, choose its destination, and save. Choose **Unclassified** to remove its category assignment.

If you have uploaded attachments to a new task but have not sent a message, you can still change the category above the input box. Your text and attachments are kept.

Pinned tasks appear in **Pinned** while retaining their category. Unpinning a task returns it to that category.

## Rename or delete a category

Use the action menu beside a category to rename or delete it.

Deleting a category moves its tasks, including archived tasks, to Unclassified. All task content and pin status are kept.
