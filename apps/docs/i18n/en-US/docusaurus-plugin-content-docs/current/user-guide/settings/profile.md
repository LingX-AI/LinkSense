# Profile and personal usage

Open **Settings → Profile** to manage visible account information and usage insights.

## Display name

Edit and save the name shown in the sidebar, administrator user lists, and other safe identity displays. It does not change the login email.

## Avatar

Upload a supported image from the avatar area. LinkSense validates its type and size. Replacing an avatar changes display only and never changes task ownership.

## Personal usage

The profile can show total tokens, tasks, turns, model calls, active days, average tokens per turn, a 365-day activity heatmap, and current or longest streaks.

These values are insights, not usage settings, billing, or execution controls. Minimal activity and usage facts may remain after task deletion without restoring task content.

## Update failures

Correct inputs that violate visible limits and retry. A disabled account loses its active session and cannot continue profile changes.
