# Quota and usage analytics

Open **Settings → Quota** to view your own quota and usage. Self-registered users and organization members use the same page.

## Overview

View credits used, credits remaining, your weekly limit and the next reset time. Unlimited accounts still show actual consumption. Weekly quotas reset every Monday in the system time zone. After an administrator resets your quota, the overview counts usage since that reset; analytics retain historical charges.

Credits are rounded to the nearest integer for display. Actual charges keep their fractional precision. Usage below half a credit may display as 0 but still contributes to totals.

## Analytics

Choose the last 7 or 30 days. Dates use your browser's time zone. The 30-day range is an analytics window, not a monthly quota.

- Credit history: daily charges by workload or model, based on recorded charges at the time of consumption.
- Task ranking: expand model and workload details or open a task. Other usage and deleted tasks are grouped separately.
- Plugin and MCP calls: finished calls in retained tasks, including failures. Activity counts are not charge counts.
- Skills: the same skill counts once per turn.
- Messages: user messages in task turns, grouped by model. Excludes AI replies, queued messages and history copied into forks.

Charts show up to five categories, grouping smaller categories as **Other**. Independently rounded category values may not add up exactly to the displayed total.
