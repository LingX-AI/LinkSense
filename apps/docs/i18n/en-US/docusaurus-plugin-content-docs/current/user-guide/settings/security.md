# Security and password changes

**Settings → Security** changes a local login password. An SSO-only account may not need this operation.

## Change the password

1. Enter the current password.
2. Enter a new password that passes the page rules.
3. Confirm the new password.
4. Submit.

After success, LinkSense revokes all sessions and requires sign-in again, including on other devices.

## Password quality

Follow live validation. Avoid organization names, email addresses, common phrases, and passwords reused in another system.

## Forgotten password

Return to the login page and request a one-time reset link. If authentication email is not configured or unavailable, ask an administrator to restore that capability.

## Safety

- Administrators never need your password.
- Do not place it in a task, credential name, MCP description, or custom instruction.
- For suspicious sign-in behavior, change the password and give an administrator only the time and non-sensitive symptoms for audit review.
