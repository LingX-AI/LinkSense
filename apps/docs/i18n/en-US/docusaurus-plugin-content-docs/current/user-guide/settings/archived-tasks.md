# Archived tasks

Open **Settings → Archived tasks**.

## Restore

Unarchiving returns a task to the recent list using its latest activity order. It does not rerun a historical turn.

## Delete one task

Permanent deletion requires confirmation and cannot restore the task body, attachments, messages, or accessible deliverables.

## Clear all archived tasks

This action affects only your archived tasks, not unarchived work. Download anything important first because the operation cannot be undone.

## Retained facts

Minimal audit, security, resource cleanup, and usage facts may remain after hard deletion. They can include task or turn counts and token or cost snapshots, but not recoverable titles, message bodies, file content, or tool arguments.
