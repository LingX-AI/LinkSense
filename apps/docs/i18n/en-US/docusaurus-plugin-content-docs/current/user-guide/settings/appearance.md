# Appearance and text size

Open **Settings → Appearance** for display preferences.

## Theme

- **System** follows the operating system or host WebView and responds to changes.
- **Light** always uses the light interface.
- **Dark** always uses the dark interface.

Theme changes do not affect task content, files, or execution.

## UI font size

Adjust the base size within the page's allowed range. Navigation, forms, controls, settings, and task UI scale together while preserving hierarchy.

Document, Markdown, Office, or PDF preview content may have its own viewer zoom.

## Across environments

The appearance preference is applied in Web and Teams for the current browser environment. System mode can resolve differently on different devices.

Use a document viewer's zoom if only preview content is crowded instead of reducing the entire LinkSense UI.
