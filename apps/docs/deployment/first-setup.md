# 首次配置

## 创建首位管理员

打开安装器打印的地址。默认端口为 `18081`；如果端口被占用，新安装可能自动选择其他端口，实际地址可通过 `linksense address` 查询。使用安装器提供的一次性凭据创建首位管理员。不要把凭据粘贴到聊天、工单或公开日志。

## 配置模型

按[模型设置](/admin-guide/model-settings/)添加模型渠道，并在管理界面保存配置。兼容服务的网络连通性、模型协议和工具能力需要分别验证。Full 使用知识库时，还需配置相应的向量模型。

## 验证首个任务

1. 运行 `linksense status` 和 `linksense doctor`，确认部署健康。
2. 按[首个任务指南](/user-guide/getting-started/first-task/)发送一条简短消息。
3. 运行一次会使用工具的任务，例如生成并打开一个小文件。能对话不等于工具可用；确认实际产出。
4. 使用 Full 时，上传一个代表性文档并检查检索结果是否引用正确来源。

对外开放前，先阅读[部署运维说明](./operations.md)和[执行安全边界](./architecture.md#执行边界)。
