# Social provider brand assets

- Google: the multicolor Google mark from the installed `react-icons/fc` package, rendered without a surrounding border or background.
- Microsoft: official [Microsoft symbol SVG](https://learn.microsoft.com/en-us/entra/identity-platform/media/howto-add-branding-in-apps/ms-symbollockup_mssymbol_19.svg), with its four original fills. The internal title is omitted because the adjacent heading labels it.
- Facebook and Apple: reuse the installed `react-icons/si` brand paths. Facebook uses its brand blue (`#0866ff`) on white; Apple uses the foreground color for light/dark themes. These are brand colors, not application status colors.
- GitHub: reuse the installed `react-icons/si` GitHub brand mark with the foreground color, preserving the same inline logo container as other providers.

Provider names and logos remain trademarks of their respective owners.
